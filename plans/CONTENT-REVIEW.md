## 人工审核步骤

需要交接给其他审核人员时，维护者先运行 `npm run review:bundle`。该命令重新构建预览，并把同批 Markdown、来源、研究记录、本文与报告打成 `artifacts/review-bundles/` 下的本地压缩包，附 SHA-256 清单。接收方解压后，在包内 README 所在目录执行 `python3 -m http.server 4322 --bind 127.0.0.1 --directory site`，打开 `http://127.0.0.1:4322/editorial/`；需要 Python 3，无须安装项目依赖。请通过 HTTP 浏览；不要直接双击 HTML。审核包保留生成时的状态，后续源文件改变时需重新生成。

1. 阅读文章摘要与正文，对照来源区的原文、地区和版本，确认每项已知/未知陈述的范围。
2. 日语稿逐段核对与中文的事实一致性，检查名称、日期、设备及按钮说明，允许为自然表达调整句序。
3. 在桌面与手机预览检查目录、表格、官方入口和同篇语言切换；日本商店实际资格需用对应目标设备/账号验证。
4. 执行 `npm run content:readiness` 与影响查询，确认没有过期事实/译文；真实审核完成后再填写 `reviewer`、`reviewedAt` 并按 README 的发布流程改状态。

# 站点结构与阅读路径

2026-11-13 制定，2026-11-14 按用户决策修订。正式主域名为已购的 `promiliaguide.com`。首版采用简中与日语独立目录，韩语后续扩展。详细发布与校对流程见 `LOCALIZATION-PLAN.md`。

## 导航与 URL

主导航：首页、开荒攻略、角色、奇波、系统、更新。顶部提供站内搜索，手机保留可见搜索入口。

根路径 `/` 为语言选择页；语言首页为 `/zh-hans/`、`/ja/`。以下路径中 `{locale}` 取这两个值，页面仅在该语言内容完成时生成。`/ko/` 尚不公开。

```text
/                                  语言选择
/{locale}/                         当前语言首页
/{locale}/guides/                  攻略目录，内容充足后独立发布
/{locale}/guides/launch/            公测日期、预约与开服时间，注明地区
/{locale}/guides/global-release/    国服与全球发行状态
/{locale}/guides/download/          下载入口、客户端与地区条件
/{locale}/guides/platforms/         已确认平台及各地区上线状态
/{locale}/guides/requirements/      配置与运行平台
/{locale}/guides/getting-started/   开服准备与新手路径
/{locale}/guides/day-one/           首日路线，注明测试/公测版本
/{locale}/guides/resources/         资源与体力规划
/{locale}/guides/banner-rules/      抽卡机制及未确认事项
/{locale}/systems/combat/           战斗与元素
/{locale}/systems/kibo/             奇波玩法
/{locale}/systems/homestead/        家园
/{locale}/systems/exploration/      探索与解锁
/{locale}/characters/              角色目录与养成入口
/{locale}/characters/{stable-slug}/ 少量角色详情
/{locale}/kibo/                    奇波目录；独立详情后续扩展
/{locale}/updates/                 公告索引与本站修订记录
/{locale}/about/                   关于本站与非官方说明
/{locale}/editorial-policy/        来源、版本、编辑与纠错规范
/{locale}/contact/                 联系、纠错与素材反馈
```

URL 不包含测试批次和发布日期；同一攻略按版本维护，关键历史差异写在正文或修订记录。确有独立阅读价值的旧版本资料才单独归档并清楚标记。发行状态页回答跨地区时间，下载页回答如何获得客户端，平台页回答设备与平台支持；若资料太少导致内容重复则先合并，达到独立价值后再拆分。

所有语言页面独立校对，明确游戏地区与版本。按稳定 contentId 匹配对应文章，各自使用自引用 canonical；只有已发布且真正对应的文章才生成互相返回的 hreflang。语言标记分别为 zh-Hans、ja，韩语未来使用 ko。英文试点退出首版。

首页集合 x-default 指向根语言选择页；文章集合的 x-default 优先指向已发布的简体同篇。没有译文时不指向虚构路径、不用语言首页冒充译文，切换界面明确提供目标语言首页或标注语言的原文链接。不按 IP 强制跳转。

来源记录初期集中维护在数据文件，文章底部呈现引用；不把每条来源自动生成为可收录页面。目录页面仅在已有足够内容和导航价值时发布。

## 首页结构

1. 顶部：一句话定位、当前游戏阶段、搜索入口。
2. 首屏：公测时间/地区、官方下载、开服准备、入门攻略四个入口；开服后调整为首日行动与常用资料。
3. 当前重点：3—5 篇近期最有用的攻略，标明适用版本。
4. 常用资料：角色、奇波、家园、战斗、探索。
5. 最近修订：显示内容改了什么，而非仅列日期。
6. 页脚：非官方说明、编辑规范、来源原则、联系方式。

上线前以公测准备为首页重心；开服后切换为首日行动和已核验指南。倒计时只有在官方时间已确定时才展示。

## 内链设计

| 当前页面 | 上下文链接 | 目的 |
|---|---|---|
| 公测准备 | 配置、首日路线、抽卡机制 | 从准备进入行动 |
| 首日路线 | 战斗、家园、奇波、资源 | 在遇到系统时学习 |
| 角色详情 | 养成、相关机制、可验证的队友建议 | 从查资料进入使用 |
| 奇波详情 | 获取条件、家园/战斗用途 | 说明为何要获取 |
| 系统指南 | 相关角色/奇波、开荒步骤 | 返回实际行动场景 |
| 更新索引 | 受影响的攻略与详情页 | 直接看到变化后的结论 |

每篇正文至少有一个合理的下一步入口。使用面包屑返回目录；从相关正文推荐内容，不机械堆砌全站链接。

## 最小内容元数据

所有页面：标题、简介、作者、首次发布日期、实质更新时间、适用服务器与版本、核验状态、来源 ID；多语言增加 contentId、locale、sourceRevision、translatedFromRevision、translationStatus、reviewer、reviewedAt。

元数据可扩展为事实条目级的版本与来源；一篇文章有多个版本结论时不得仅靠统一顶部标签掩盖差异。

## 搜索与索引规则

- 角色中文名、官方外文名、常用简称作为搜索别名；非官方译名标明性质。游戏名兼容「蓝色星原」「藍色星原」「Azur Promilia」「azurpromilia」及 `azure promilia`、`azur promillia` 等已观察到的常见错拼；统一指向标准名称，不做错拼专页。
- 搜索页、无内容的筛选组合和预览页不进入 Sitemap。
- 筛选状态保持清晰的 canonical 规则，避免大量重复 URL。
- 未完成的详情页保留在草稿，不以只有名字和图片的形式公开。
- 日语名称以已核验官方来源为准；没有官方译名时标注原文或经核验的英文名，不用机器生成专名。搜索按当前语言返回，并验证中文和日语检索效果。
- 所有 canonical 与 Sitemap 采用 `https://promiliaguide.com`。Cloudflare Pages 分支预览验证 noindex，生产 pages.dev 重定向到正式域名；不把预览域名写入站点配置。

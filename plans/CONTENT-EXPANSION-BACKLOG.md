## B01 · 公测福利怎么领：登录、任务、网页活动分别看

日语标题草稿：配布報酬の受け取り方：ログイン・任務・Webイベントを分けて確認。

- 用户任务：判断自己现在能领什么、需要做什么、何时截止，以及获得的道具能用到哪里。
- 需求依据：S01、S02、S07、S19；搜索簇 event / entry。FAQ F08、F09、F11、F13、F14、F30。
- 正文结构：国服官方摘要 → 奖励来源与条件表 → 即时/分日/任务/长期区分 → 网页任务与游戏内领取 → 未到账核查 → 地区差异。
- 可立即复用的事实：O01国服官方正文“登录66抽、探索与任务累计510抽以上、指定任务免费五星角色与五星灵子”。不将66与510相加，不推广到日本。
- 采证表：地区、版本、活动名、原始URL、任务/等级前置、奖励原名、票券适用池、时间性质、开始/截止及时区、绑定与兑换条件、与其他奖励是否重叠。
- 完成标准：每个表格数字可追溯；未知行明确标记；读者能区分活动参与截止与领取截止；跨页不重复维护冲突数字。日本行用日本独立原文填写，再做日语审核。

## B02 · 票券和保底怎么查：先确认卡池，再算投入

日语标题草稿：ガチャ券と天井の確認方法：対象ガチャと引き継ぎ条件。

- 用户任务：判断手中道具能否用于目标池，理解概率、保证与跨期计数的区别。
- 需求依据：S01、S02、S04、S23；搜索簇 banner。FAQ F15—F17、F34。
- 正文结构：票券对应表 → 各池规则分栏 → 计数范围与继承示例 → 期望/分位数/上限 → 消耗前检查。
- 采证表：地区/版本/池名、有效期、票券原名、转换规则、概率原文、保底阈值、计数对象、跨期继承范围、保证重置、官方示例与例外。
- 完成标准：不用社区标题或旧测试填精确值；完整规则前不发布计算器、期望抽数或氪金建议。资源页负责“从哪领”，本页负责“用到哪、如何计数”。

## B04 · 首日只做有用的事：低负担路线与可选分支

日语标题草稿：初日の進め方：無理のないルートと後回しにできること。

- 用户任务：从创号走到关键系统解锁，知道当前为何做、卡住看什么，按自己时间选择探索量。
- 需求依据：S06、S16、S09；FAQ F10、F20、F25、F31、F32。不存在本轮直接联想词量证据。
- 正文结构：起点条件 → 主流程 → 奖励时限检查 → 系统解锁节点 → 可延后支线 → 卡住分岔 → 下一次上线检查。
- 采证表：地区/版本、任务名、前置、地图或入口、完成操作、解锁结果、实际用时范围、可选性、失败/回退路径。
- 完成标准：正式版至少完成一次可复核主流程，步骤与截图/记录对应；三测内容单列版本差异；不承诺一日毕业或固定账号进度。篇幅和独立价值不足时合入现有getting-started。

## B05 · 家园怎么开：设施、岗位与第一轮产出

日语标题草稿：ホームの始め方：解放条件・施設・キボの配置。

- 用户任务：完成解锁、理解岗位、安排一次实际生产，并能排查不产出原因。
- 需求依据：S05、S06；FAQ F21、F27、F36。高播放攻略明确基于三测，这是正式验证重点。
- 正文结构：解锁前置 → 第一座设施 → 工种与能力 → 产出/仓储 → 离线结算 → 停产排查。
- 采证表：任务链、设施名称、成本、岗位、奇波要求、投入/产出、仓储与上限、结算周期、离线边界、版本变化。
- 完成标准：一条完整操作路径；不能核实的效率和成本不填；“必须先开”的说法须有依赖链证明。新路由只在内容与审核齐备后生成。

## B07 · 不想打PvP，哪些事项需要确认

日语标题草稿：PvPへの参加は必要？報酬と育成への影響を確認。

- 用户任务：判断能否跳过竞技，以及跳过会错过什么。
- 需求依据：S03；FAQ F23。当前只有一条较明确的社区讨论，不能称跨平台一致热点。
- 正文结构：玩法是否存在及当前开放 → 入场条件 → 必须/可选 → 奖励与替代 → 低参与选择。
- 采证表：正式玩法入口和说明、任务依赖、奖励表、刷新、排位/匹配、替代来源。
- 完成标准：未核清前只交付核查项，不写“有PvP所以逼氪”或“完全不用碰”；先在新手页给足答案，除非内容形成独立流程再拆页。

## B09 · 每天该做什么，一个周期能获得什么

日语标题草稿：デイリー・ウィークリーと継続入手リソースの整理。

- 用户任务：在有限时间里安排任务，区分首发福利与长期资源。
- 需求依据：S01、S06、S16；FAQ F25—F28、F31、F33、F34、F36。
- 正文结构：时间预算分层 → 日/周刷新 → 一次性/持续性来源 → 票券分池 → 缺勤/补领 → 周期合计。
- 采证表：地区、版本、任务、刷新时区、条件、单次奖励、周期次数、票券、可补做性、实际用时、是否付费。
- 完成标准：D4起可先写已核单项；完整周期数据后才给周期总计；付费来源另列；不将510抽或未核月卡收入平均成固定月收入。

## B10 · 自选和长期投入：按用途补少量详情

日语标题草稿：選択報酬と育成先の考え方：手持ちと目的から選ぶ。

- 用户任务：确定自选的期限/候选，并按当前缺少的功能比较投入。
- 需求依据：S06、S15、S12—S14官方传播；characters搜索簇。FAQ F18、F19、F28、F35、F37。
- 正文结构：自选条款 → 现有阵容/用途 → 功能比较 → 成本与替代 → 使用前确认。先补1—3个证据足、能独立解决问题的详情。
- 采证表：正式候选名单、期限、是否可撤回、技能/用途、养成成本、场景、测试条件、分语言名称与字段来源。
- 完成标准：角色热度、外观偏好与战斗能力分开；不拿抽奖转发或官方点赞当强度；不批量生成薄详情或全角色梯度榜。

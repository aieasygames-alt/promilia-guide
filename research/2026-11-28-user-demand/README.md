# 公测后玩家需求与内容更新研究 — 2026-11-28

本轮结论：先修正地区与语言入口，再把“入门介绍”推进到“能照着完成的攻略”。优先主题为每日周常解锁、捕获卡与孵化卡差异、星彩／闪光与稀有奇波、飞行与高处宝箱、家园自动种子和耗粮、自选角色配队。不要把主要精力继续放在泛化公测新闻或没有正式版依据的全角色榜单。

这是定向公开研究和开发规划；没有修改公开攻略或部署网站。所有观察日期为 **2026-11-28，Asia/Shanghai**；平台未说明时区的发帖时间保留原样。后续执行详见[更新计划](../../plans/2026-11-28-demand-update-plan.md)。

## 6. 优先级与验收方式

按“影响玩家当前决策 → 多来源重复出现 → 现有页面缺口 → 答案可验证 → 独立开发成本”顺序作编辑判断，不合成虚构SEO评分。

1. **近期可完成：** P0地区／语言／官方入口和最新通知；在现有三语言页维护1份地区事实表，核清SEA和Global。
2. **主要增长：** P1日周常、奇波机制、移动、家园、自选配队与活动。每篇至少完成1条实际可复现的任务路径，正文首段直接回答，配操作图和地区版本。
3. **较高制作成本：** P2先做1个小区域收集路线；暂不铺全地图和全角色强度榜。

适合搜索和AI直接引用的形式是“条件＋动作＋结果＋地区／日期”，例如每日解锁前置表、卡片用途对照、地区版本表。AI是否引用及Google是否显示图片由平台决定，不能承诺。引用官方图／玩家图需保留来源并核使用许可，优先使用有权使用的正式客户端实测截图；禁止把他人整张路线图或攻略改写后当本站实测。

完整任务ID、URL、证据门槛、7日排期、语言顺序和上线后7／14日衡量见[内容更新计划](../../plans/2026-11-28-demand-update-plan.md)。本轮不因研究文件变更运行应用构建或推送IndexNow；后续公开页面实际更新后再执行发布与线上验证。

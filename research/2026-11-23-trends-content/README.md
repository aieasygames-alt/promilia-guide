## 对上一轮截图判断的补充

实际打开用户现有Trends页后确认，截图对象是**连写搜索词AzurPromilia**，全球、过去一个月、网页搜索，并非游戏主题。该页显示的>5,000%不能用来描述整个游戏的增长；当次关联Top与Rising各只有2条。

随后以既有研究的主题ID `/g/11vysqzgty` 补查同一时间范围。游戏主题当次显示较前月+140%、同比+2,800%；11月20日97、21日100、22日82，23日100为部分数据。地区前五为韩国100、台湾50、澳门31、中国27、香港26。不同对象的榜单不混用，地区指数也不是绝对搜索量。

逐页查看主题Top 50与Rising 50。保存的是浏览器所见的[重点查询摘录](queries.json)，不是完整CSV导出。可用于本轮内容的信号包括：

- 日语PC（Top第13、指数6、+140%），以及アズプロ PC、PC版的上升词。
- 日语官网（Top第26、指数3、Breakout）、アズプロ リリース日、事前登録。
- 繁简中文的日服、国际服，以及繁中预约、角色。
- PS5查询存在，但不能证明官方支持；用FAQ回答证据范围。
- Silver Palace、Ananta等其他游戏、过宽的单词和错拼不独立建页。本次Top/Rising各50条未见明确codes、tier list或wiki，不能据此断言这些需求为零。

因此，本轮完善9个既有主题，没有为了每个近义查询新增薄页，也没有扩展网站语言。

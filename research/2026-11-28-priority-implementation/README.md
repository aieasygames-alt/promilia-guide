## 验证与发布方法

本批执行项目的类型检查、72项单元测试、预览构建、120项桌面／移动浏览器回归、生产发布门槛及正式构建。默认4321端口被已有服务占用，浏览器回归使用`PLAYWRIGHT_PORT=4337`，不停止用户原服务。具体成功结果以运行输出、PR检查和生产验收报告为准。

```sh
PLAYWRIGHT_PORT=4337 npm run verify:release
npm run site:verify -- --url https://promiliaguide.com --mode production --commit FULL_SHA --redirects --json
```

按既有Git集成流程发布到Cloudflare Pages。上线后以`build-info.json`的完整SHA核对本次版本，再检查实际正文、官方链接、语言切换、canonical、hreflang、图片、真实404和域名永久跳转。线上报告、截图与IndexNow实际响应保存至忽略目录`artifacts/priority-content-2026-11-28/`；IndexNow只提交本批实际变更的canonical URL，接收不等于收录。最终PR、提交与检查结论由本次会话交付。

尚无更新的公测后Webmaster数据，不宣称本批提高了CTR、排名或流量。后续按队列的7日／14日口径观察；没有创建定时任务。

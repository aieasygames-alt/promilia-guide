## 从哪里审核

构建完整预览：`npm run review:bundle`。生成的压缩包和SHA-256保存在`artifacts/review-bundles/`。这是noindex编辑材料，不是生产发布包。

解压后进入`promilia-review`目录，执行：

```sh
python3 -m http.server 4322 --bind 127.0.0.1 --directory site
```

从 `http://127.0.0.1:4322/editorial/` 查看全部稿件。推荐按下表逐篇核对，表内路径均相对于`site`服务；中文和日语对应路径只替换语言前缀。

## 当前结论

此前登记的前瞻回顾不能从原始链接复核，暂不把80抽不歪、武器60抽保底、新手50抽八折、自选箱或永久继承写作正式规则。中国大陆与日本的规则需要各自的官方依据。

## 进入卡池前核对这张表

| 项目 | 需要的原文信息 |
| --- | --- |
| 适用池与地区 | 卡池名称、服务器、活动起止时间 |
| 概率 | 最高稀有度与当期目标概率，是否存在阶段变化 |
| 保底 | 触发次数、具体获得对象、提前获得后的计数处理 |
| 继承 | 同期与跨期、同类型与不同类型卡池分别说明 |
| 代币 | 可用池、转换方式及是否有到期或自动转换 |
| 新手与自选 | 获取条件、可选范围、关闭条件和有效期 |

## 证据不完整时如何安排资源

这是编辑上的准备建议：先保留未分配的稀缺资源，等目标卡池完整条款可读后再决定。不要用其他作品的保底次数计算本作预算，也不把官方福利总量等同于立即可用于限定池的抽数。

## 手机要留多少空间？PC要留多少？

**11月24日国服和日本各自的公测FAQ均建议：Android、iOS预留55GB以上，PC预留120GB以上；PC推荐安装在SSD。** 国服FAQ另列鸿蒙端，建议同样预留55GB以上。它们是官方建议的安装前剩余空间，不能写成“实际下载55GB”或“安装后一定占120GB”。

本页配置来自[国服公测FAQ](https://azurpromilia.manjuu.com/home/news/detail/912070871064121344/)和[日本正式服务FAQ](https://azurpromilia.jp/news/5190)，均于11月24日发布并逐份读取。两地表格相似，各自适用范围仍分开保存；后续调整以对应地区原文为准。

## 日本版手机与PC配置

| 项目 | 最低配置 | 推荐配置 / 建议预留 |
| --- | --- | --- |
| PC系统与接口 | Windows 10 64-bit及以上；DirectX 11.1及以上 | PC推荐SSD |
| PC处理器 | Intel Core i5-9400F或同级 | Intel Core i7-10700K或同级及以上 |
| PC显卡 | NVIDIA GeForce GTX 1060或同级 | NVIDIA GeForce RTX 2060或同级及以上 |
| PC运行内存 | 16GB | 16GB及以上 |
| PC存储空间 | FAQ未单列“最低空间” | 建议预留120GB以上 |
| Android系统 | Android 10.0及以上 | — |
| Android芯片 | 骁龙855、天玑1000+、麒麟990或同级及以上 | 骁龙8 Gen1、天玑9000+或同级及以上 |
| Android运行内存 | 6GB | 8GB及以上 |
| Android存储空间 | FAQ未单列“最低空间” | 建议预留55GB以上 |
| iOS系统 | iOS 15.0及以上 | — |
| iPhone机型 | iPhone 12 Pro | iPhone 13 Pro及以上 |
| iOS存储空间 | FAQ未单列“最低空间” | 建议预留55GB以上 |

日本FAQ没有单列iPad推荐机型，也没有单列iOS运行内存要求。不要用国服内存行补进日本表格。达到最低条件不保证特定帧率或最高画质；本页没有做设备性能实测。

## 国服配置与鸿蒙端

国服FAQ独立列出：PC的系统、DirectX、CPU、GPU、内存和建议空间，以及Android的系统、芯片、内存和建议空间，与上表对应数值相同。iOS同样列iOS15.0、最低iPhone12Pro、推荐iPhone13Pro及以上、建议预留55GB以上。

国服原文还列有以下条目，不推广为日本要求：

| 项目 | 国服FAQ原文条件 |
| --- | --- |
| iOS运行内存 | 最低6GB；推荐8GB及以上 |
| 鸿蒙系统 | HarmonyOS 5.0及以上 |
| 鸿蒙设备 | 推荐麒麟9020同级别及以上芯片 |
| 鸿蒙运行内存 | 推荐12GB及以上 |
| 鸿蒙存储 | 建议预留55GB以上 |

iOS机型与内存是公告分别列出的字段，本页按原文并列保留，不自行修改机型或推算设备内存。国服商店的iPadOS15.0是商店兼容条件，不能代替游戏推荐机型。

## 3.9GB、约3.64GB与55GB为什么不同？

| 数值 / 字段 | 来源与含义 | 不能据此判断什么 |
| --- | --- | --- |
| 3.9GB | 中国区App Store当前分发大小 | 日本版大小、全部资源或安装后占用 |
| 3,644,462,080字节，约3.64GB（十进制） | Apple日本区应用元数据的fileSizeBytes，版本1.0.0 | 完整空间、追加资源大小或当前可安装状态 |
| 手机55GB以上 / PC120GB以上 | 两地FAQ建议预留的剩余存储空间 | 实际下载量、实际安装占用或最低空间 |
| 客户端追加资源大小 | 按客户端当次提示确认 | 尚未看到的后续更新量 |

两地FAQ都说明安装本体后还需要客户端内追加资源。不要只按商店包体腾空间，也不要把建议预留值与商店大小相加成“总下载量”。本轮未安装游戏，没有实测完整下载量、解压临时空间或安装后占用。

日本App Store网页本次仍跳至Today；上面的日本元数据来自[Apple日本区lookup接口](https://itunes.apple.com/lookup?id=6787982572&country=jp)，已核对应用ID6787982572、名称和Yostar发行者。元数据的releaseDate字段不作为服务器开服时刻。

## 如何检查自己的设备

1. iPhone / iPad：在“设置 → 通用 → 关于本机”核对型号和系统，在储存空间中查看剩余容量。iPad推荐机型需继续核实。
2. Android / 鸿蒙：分别记录系统、芯片、运行内存和剩余存储；RAM不是磁盘空间。
3. Windows：在系统信息记录CPU与内存、任务管理器核对GPU、文件资源管理器检查实际安装磁盘的剩余空间；本体和更新都优先确认SSD目标目录。
4. 若不满足要求，先记录不符项目。能进入商店或看到下载按钮不等于设备达到游戏最低配置。

## 空间足够但读条慢、闪退，先核对什么？

日本[FAQ第4节](https://azurpromilia.jp/news/5190)把容量不足、PC加载慢与游玩中强制关闭分成不同问题。排查时先记症状，再对应检查项：

| 症状 | 设备与存储检查 | 后续动作 |
| --- | --- | --- |
| PC安装／更新报空间不足 | 记录实际安装目标盘剩余空间，不能只看其他磁盘 | FAQ建议整理不需要的文件或选择更宽裕的安装目标 |
| PC启动或加载慢 | 记录是否SSD、目标盘空闲；对照上方CPU、GPU和RAM | 日本FAQ推荐SSD及足够空间，不保证某个读条秒数 |
| 游玩中反复闪退 | 记录机型、OS、发生时间，区分未启动与游玩中关闭 | 日本FAQ先要求重启设备，再启动游戏；反复发生附记录向客服反馈 |
| 下载完但登录被阻止 | 核对地区与开服／维护状态 | 服务未开放与设备性能问题分别判断 |

最低条件不是稳定帧率或绝不闪退的保证。FAQ提到低于最低配置可能出现迟缓、掉帧和发热，但没有给出“某个症状必定由某硬件引起”的诊断。先用[下载页的阶段排查与客服信息表](/zh-hans/guides/download/)确认下一步，或下载[本地故障记录表](/downloads/launch-troubleshooting-zh-hans.txt)。这些处理步骤按日本原文限定，国服请查当地对应说明。

## 容量、iPad与跨端常见问题

### 日本版iPad能玩吗？

日本FAQ写iOS要求和iPhone机型，没有给出独立iPad推荐表。Apple元数据中的设备列表和iPad截图不作为流畅运行保证。中国区iPadOS兼容条件也不直接套用到日本版。

### 55GB是内存还是存储？

是建议预留的存储空间。日本Android最低RAM为6GB、推荐8GB及以上；PC最低RAM16GB。不要把55GB当运行内存。

### PC与手机能共享进度吗？

日本FAQ确认同一账号的PC、Android、iOS进度共享；国服官方服务器确认同一账号PC、Android、iOS、鸿蒙进度共享。部分渠道服与国服官方服不互通。跨地区账号、付费货币和渠道转服不由此确认，见[平台规则](/zh-hans/guides/platforms/)。

### 空间够了，下载后为什么仍进不去？

预下载与服务器开放不同。两地计划在11月26日北京时间10:00、日本时间11:00开启服务；实际状态仍看各地区公告。按[下载与资源更新步骤](/zh-hans/guides/download/)完成本体和追加资源，再用[准备清单](/zh-hans/guides/getting-started/)记录账号与领取事项。

## 预下载已公告开始，容量够了去哪里下？

两地均已发布开始公告。日本PC有[官方Windows独立下载页](https://azurpromilia.jp/PCdownload)，国服官网已显示PC和Android下载按钮；本轮没有取得安装文件或测量完整占用。国服App Store后续刷新为1.0.1、3.9GB，分发体积仍不能替代55GB建议预留。按[下载与追加资源步骤](/zh-hans/guides/download/)继续，先核对地区和渠道。

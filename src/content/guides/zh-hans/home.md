## 家园不生产或缺粮，先看这几处

**先找缺种子、缺食物、岗位不匹配或仓库已满的提示，再决定是否扩建。** 本页整理国服、韩国玩家的界面参考和日服寮商品说明，各段标明地区；完整解锁等级与自动生产效率尚无本站实测。

| 你遇到的问题 | 优先查看 |
| --- | --- |
| 没有继续种植 | 种子库存、种子管理设置、播种／浇水／收割岗位 |
| 奇波吃不饱 | 奇波餐桌、食物库存和当前派遣数量 |
| 工人有了但没产出 | 岗位能力要求、材料、运行状态与暂停提示 |
| 看得到产物但背包没有 | 仓储上限与收取状态 |
| 家园入口没开放 | 当前主线与功能锁定条件 |

## 种子管理在哪里？韩国版界面参考

[韩国玩家Horol的11月27日图文](https://arca.live/b/azurpromilia/190507810)给出了三张界面图，补足“种子管理在哪里找”的线索：**家园总览下方「키보 농장」→农场右下「씨앗 관리」→「씨앗 창고」种子槽**。以下保留韩语标签，其他版本的菜单名与位置可能不同。

1. 在已开放的家园总览找农场入口；若还未开放，按当前主线／功能锁定提示继续。
2. 进入农场，查右下的种子管理；先看已有种子数量和种子槽配置。
3. 原帖种子仓库说明按设置顺序栽培。按自己所需作物配置，再回到农场确认岗位、作物与食物状态。
4. **设置后回到农场查看运行状态。** 种子配置与收获物自动领取是不同选项；自动运行效果尚未经本站实测。

作者说自己21级才发现该功能，这不是21级解锁的依据；“每15–20分钟手动回来种麦”也是个人经历，不作为统一作物周期。国服已有[首日家园原帖](https://www.taptap.cn/moment/875088587471717682)列出种子管理与岗位，可对照本服界面查找，不能直接照抄韩语按钮位置。

## 国服种植、餐桌和订单怎么找

11月26日TapTap玩家雅中林阁发布[家园1–15级规划](https://www.taptap.cn/moment/875088587471717682)，明确说明未参与内测、依据当天个人体验。帖子列出「耕作小屋」「奇波餐桌」「订单看板」「奇波牧场」，并展示播种、浇水、收割分工及种子管理选项。**这是国服玩家的个人路线，评论中有补充修正；设施等级和槽位请以当前版本为准。**

| 当前想解决的问题 | 结合帖子可找的界面线索 | 执行前核对 |
| --- | --- | --- |
| 种植没有连续进行 | 耕作小屋中的播种／浇水／收割岗位、种子管理与自动领取收获物种子 | 岗位能力、种子库存、设施是否开工 |
| 想播高星种子 | 查看种子管理内是否有「优先播种高星种子」 | 稀缺种子用途与任务需要，先读开关含义 |
| 工人吃不饱 | 奇波餐桌及食物补充入口，帖子提到「一键添加」 | 配方材料、食物库存、当前净消耗 |
| 不知道当前生产什么 | 订单看板的实际需求 | 先生产当前订单或推进所需物资，别只按稀有度排满 |

## 派满反而缺粮？先核对额外岗位的收益

11月27日核查的另一篇[玩家耗粮反馈](https://www.taptap.cn/moment/875286112719866850)描述：排满岗位后食物供应吃紧，部分加速或返还被动带来的收益不抵新增食物消耗。帖子没有完整受控配置，不能据此断言所有金色词条都差，或发布统一每小时效率。

食物持续减少时，建议先维持必需的生产岗位，检查餐桌补给，并减少暂时用不到的额外岗位。添加辅助岗位前，先看新增产出能否抵消耗粮；观察库存时留意手动补粮、任务奖励和订单消耗。具体收益随配置变化，目前没有可通用的效率表。

## 日本农园新增寮：装饰商品不等于生产解锁

日本[正式上线公告](https://azurpromilia.jp/news/5225)确认農園内可放置「寮」与角色交流，塗山小玉专用「春還る花亭」售至2027年1月5日04:59 JST，メーツァ专用「翠緑の秘苑」常驻销售。套装包含装饰、睡衣及头像等内容；这没有说明国服设施解锁等级、生产加成或必购前置。按自己地区的界面核对。

## 没有产出时，按什么顺序排查？

先读设施的停止提示，再检查**材料和种子→岗位能力→食物→计时→仓储与收取**。如果增加派遣后食物持续减少，可以先减少额外岗位，优先维持眼前需要的生产。

岗位适不适合，要看奇波能力和设施要求；稀有度高不代表适合所有工作。孵化或装备制作需要相应前置和材料，具体入口按本服教程操作。

## 先扩建还是先培养角色？

以当前卡点为准：缺任务材料时先找对应来源；想领取家园等级或商店奖励时，先看门槛和兑换成本。国服福利图中家园等级、家园商店各列纯粹忆痕×8，属于不同资源来源，领取与兑换各有条件。

家园暂时没解锁，可以先推进[主线入门](/zh-hans/guides/getting-started/)；需要选岗位伙伴时看[奇波用途](/zh-hans/systems/kibo/)，找奖励则看[福利领取](/zh-hans/guides/resources/)。

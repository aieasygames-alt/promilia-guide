## 家园先解决哪一个问题

家园的解锁任务、设施操作和正式版岗位规则尚未完成核验。本页先帮助你区分奖励、产出与派遣条件，留下第一次解锁和生产记录；不提供未经验证的建筑顺序或“毕业”效率表。

国服11月20日福利图把家园等级和家园商店列入“永久可取”，各列纯粹忆痕×8。这证明公告列了这些资源来源，不证明登录即送、商店免费、无限兑换或设施每小时能产出票券。日本地区另核。

## 官方已经说明的家园玩法

国服App Store的开发者介绍列出开垦土地、种植孵化和制作装备，并说明奇波可以入驻家园，协助种植、采集、制作与生产。这里确认的是玩法类别，具体设施名、投入与岗位能力仍需正式客户端核对；不表示每只奇波都能做所有工作。

日本Google Play独立说明与「キボ」协作管理「農園」并战斗。日语版统一采用该官方描述中的「農園」；国服的工种清单不直接当作日本全部设施规则。

| 想先体验什么 | 开放后先验证的一个结果 | 需要留下的依据 |
| --- | --- | --- |
| 开垦与种植 | 完成一次实际可用的种植并收取 | 解锁任务、种子/材料、开始与收取前后库存 |
| 孵化 | 完成一次当前可用的孵化 | 蛋的来源、装置、成本、时间和结果 |
| 装备制作 | 做出一件已解锁配方的装备 | 配方来源、材料消耗、制作与任务奖励分别记录 |
| 奇波协作 | 对比一次分配前后的状态 | 个体能力、岗位要求、产出与停止提示 |

以上是正式服可用后的验证目标，未填入虚构任务名或固定建造顺序。日本节目1:10:14起还有农园说明，但自动字幕尚未与画面对照，不据此补效率、交易价格或设施等级。

## 奖励与生产分开记录

| 看到的内容 | 要先问什么 | 不能直接得出的结论 |
| --- | --- | --- |
| 家园等级奖励 | 达到哪个等级，在哪里领取，是否已领 | 每升一级都送相同数量 |
| 家园商店 | 花什么货币、库存与刷新如何、购买前置是什么 | 公告列总数就能无成本全部领取 |
| 设施产出 | 投入、岗位、计时、仓储和领取操作是什么 | 资源表金额等于每小时收益 |
| 派遣或岗位 | 能力要求、是否已分配、缺少什么条件 | 按稀有度最高就一定最合适 |

## 第一次解锁时按顺序留下记录

1. 在当前任务或系统锁定提示中确认任务名和前置，不用其他地区或三测等级直接替代。
2. 进入后先读系统教程，记录第一座可用设施、用途、成本与操作入口。
3. 如果界面要求安排奇波，查看岗位要求与可用能力；没有岗位能力证据时不按排行投入。
4. 在开始前记录库存、输入与预计结束，领取后对照实际变化；区分一次性任务奖励与持续生产。
5. 下线前核对仓储、计时和暂停条件。离线是否继续、能持续多久，要以规则或复现记录为准。

这是一份核查顺序，不表示正式客户端已确认按这五步解锁。遇到不存在的界面项目，记录当前版本与显示，不为完成表格猜操作。

## 没有产出时怎么排查

先检查是否真正完成解锁、设施是否启动、材料是否满足、岗位是否适配、计时是否结束、储存是否已满、奖励是否需要手动领。每次只改一个条件，记录改动前后；不能由单次结果推出所有设施的离线规则。

| 记录项 | 填写方式 |
| --- | --- |
| 地区/版本/设施 | 使用当前界面完整名称 |
| 任务与岗位前置 | 记录提示和已完成条件 |
| 奇波与能力 | 按游戏内原文，不自行推断工种 |
| 投入/时间/产出 | 分别记开始前、结束后与领取后 |
| 停止原因 | 满仓、缺料、岗位、未解锁或尚未定位 |

## 先扩建还是先养角色

先列出当前阻塞。若只是想领取某项等级或商店奖励，先查对应门槛与兑换成本；若需要材料，再比较设施产出和其他来源。成本、周期和替代路径不明时，暂不依据“晚开就亏”投入全部稀缺资源。

从[首日准备](/zh-hans/guides/getting-started/)进入具体任务安排，查[资源分类](/zh-hans/guides/resources/)区分奖励口径，选岗位前参阅[奇波入门](/zh-hans/systems/kibo/)。

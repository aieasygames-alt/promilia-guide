## 先跑通一条产线，再扩大派遣

**先看当前订单需要什么，再倒推原料、加工设施和奇波岗位；配方锁住先查「心得」，没有田先开地，缺粮先缩减暂时用不到的岗位。** 能持续产出当前需要的东西，比一开始把所有岗位派满更有用。

| 当前卡点 | 查看与处理 |
| --- | --- |
| 工作台配方上锁 | 查看配方的前往查看／心得入口；解锁要求、可用点数与材料 |
| 有种子却不种 | 检查是否开地、种子仓库和三个种植岗位；播种、浇水、收获是否缺人 |
| 工人有了却停产 | 读设施的停止提示；原料、工作适性、食物、仓储 |
| 不知道生产什么 | 先读订单，再看行情；原料够不够、是否还要加工 |
| 派满后持续缺粮 | 保留当前需要的产线，减少额外岗位；餐桌补给和食物库存变化 |

下面的开荒路线参考[夜某（YaMou）11月26日发布的图文](https://forum.gamer.com.tw/C.php?bsn=79865&snA=696)。这是带截图的繁中社区攻略；保留原菜单名称供对照，快捷键按作者PC界面记录。其他地区、手柄及改键后的操作以当前客户端为准。国服和韩语界面的补充另列在后文。

## 第一次整理家园：工作台、心得、开地、种子

### 1. 配方上锁时，先查心得

夜某的路线先回家园查看工作台：作者把「0/1」标记作为还没制作过的项目线索。缺材料就去对应来源采集；如果项目处于锁定状态，先点「前往查看」找解锁条件，也可从选单进入「心得」，查看工業、農牧相关项目。

优先找能解决眼前缺口的配方：订单缺加工品，就先找对应加工；种植无法运行，就先看农牧相关条件。**不要把缺材料和未解锁混为一谈**，也不必为了清掉所有标记用完材料。原帖建议积极使用心得点数，这里不把它写成所有账号都适用的固定加点顺序。

### 2. 有设施还要检查是否开地

原帖提醒，家园升级后容易漏掉开地操作。作者PC界面用 **E锄地**，再通过「耕作小屋」安排种植。若你已经有种子、有人手却迟迟不种，先回到田地确认可耕作区域，不要直接去抓更多工人。

接着分开检查三件事：

1. 可用田地是否已经开好。
2. 「種子倉庫」是否放入想种的种子，并按需要排列顺序。
3. 播种、浇水、收获对应岗位是否有合适奇波。

夜某列举小麦、玉米、胡萝卜作为前期作物，并描述配齐岗位后的自动种植、收获。**这是该作者所用版本的记录**；作物是否已开放、是否能连续运行及产物如何收取，仍要看本服设施状态。种子排了队，不代表材料和食物一定够用。

### 3. 布局先照顾需要亲自走过去的设施

原帖把工作台、熔炉、烹饪锅、炼金台放在较近的位置，因为这些设施常需手动使用；订单看板及部分资源建筑则可通过 **G「家園中樞」**操作或一键收取。这是减少往返的布局思路，不是固定坐标或最高效率摆法。

先确认自己的家园中枢能操作哪些设施，再决定放远近。手柄或手机玩家按当前界面找入口；不要为了照搬PC键位重摆所有建筑。

## 订单怎么做：从成品倒推到原料

夜某给出的入口是：**工作台制作「交易站」→订单看板读需求→「行商日記」看当前集市行情→「明日預告」看后续线索**。先把当前能完成的订单跑通，再考虑为明日行情留少量余货。

| 订单处理顺序 | 查看与处理 |
| --- | --- |
| 先读需求 | 要的是原料、半成品还是成品，以及数量；别看到同类素材就直接交掉或卖掉 |
| 再查加工 | 工作台／熔炉是否有对应项目，配方是否解锁；锁配方查心得；缺原料查来源 |
| 然后排生产 | 原料库存、所需岗位、食物能否维持；先供这一单，暂停暂时不需要的产出 |
| 最后决定卖什么 | 行商日记的当前售价、自己接下来还要用多少；留够当前推进所需，再处理余货 |

作者建议先加工再出售，并用行情找售价较高的半成品或成品。**售价高不等于净收益最高**：上表是本站的安排建议，售卖前还应考虑加工消耗和当前需求；现有资料不足以给出适合所有人的最赚钱商品或固定囤货量。

「明日預告」适合帮助决定下一次上线先查什么，不必因此把所有材料压在一种商品上。原帖还提到「栗花小舖」可查看当前等级可做内容，可与工作台和订单互相对照。

## 家园币先花哪里？先看周限购，再看永久限购

原帖把家园币称为「閃亮的硬幣」，在「閃亮奇珍」查看每周限定与永久限购，作者优先推荐用于恢复体力的「原初水滴」。这是繁中作者的购买建议，不是国服、日服通用兑换表。

实际购买前，先看**剩余次数、价格、重置提示和物品用途**。若货币有限，可先比较会重置的商品与可以之后再买的永久限购，再按自己的体力需求决定；不要根据这篇攻略推定其他地区的商品名、库存或周重置时刻。

国服福利图另外列出家园等级、家园商店各有纯粹忆痕×8，领取与兑换各有条件，不能合并成进入家园立即领16抽。奖励分类见[福利领取](/zh-hans/guides/resources/)。

## 出门探索时，顺路解锁野外生产设施

夜某建议先开地图节点，再接触沿途的采矿场、伐木场、元素祭坛等野外建筑；原帖将它们与家园资源产量及部分作物开放联系起来。这解释了为什么遇到新的订单材料时，除了重排家园，还值得查看是否有尚未解锁的野外设施。

可以按这个顺序安排一次往返：**读订单缺口→查看材料来源→沿途开传送节点与相应设施→回家园检查可生产项目→再排种子和加工。** 这条往返顺序是本站依据原帖整理的游玩建议，不是完整点位路线；不能据此给出矿点坐标、解锁等级或固定增产倍率。奇波的工作能力可同时对照[奇波用途](/zh-hans/systems/kibo/)。

## 国服与韩国版：种子、餐桌和岗位入口

### 国服菜单参考

TapTap玩家雅中林阁的[11月26日家园1–15级规划](https://www.taptap.cn/moment/875088587471717682)列出「耕作小屋」「奇波餐桌」「订单看板」「奇波牧场」，展示播种、浇水、收割及种子管理。作者说明未参与内测，评论也有修正；标题中的1–15级不是本站确认的设施解锁表。

- 想播高星种子：先读「优先播种高星种子」开关，确认不会挤掉当前订单需要的作物。
- 需要补粮：到奇波餐桌看库存，使用「一键添加」前确认会加入什么食物。
- 不清楚派谁：按岗位能力要求选奇波，稀有度不能替代工作适性。

### 韩国版种子管理路径

[Horol的11月27日图文](https://arca.live/b/azurpromilia/190507810)显示：**家园总览下方「키보 농장」→农场右下「씨앗 관리」→「씨앗 창고」种子槽**，配置后按顺序栽培。作者21级才发现该入口，不等于21级才解锁；其15–20分钟手动种麦的经历也不是统一作物周期。种子顺序与产物收取要分别确认。

## 派满反而缺粮，怎么恢复生产？

[11月27日核查的国服玩家反馈](https://www.taptap.cn/moment/875286112719866850)描述派满岗位后食物吃紧，并质疑部分加速、返还被动能否覆盖新增耗粮。该帖没有完整受控配置，不能推出所有金色词条都差或统一每小时效率。

建议先保留眼前订单需要的岗位，减少暂时用不到的工作，再检查餐桌补给。恢复后逐步加回可选岗位，同时留意手动补粮、奖励和交订单对库存的影响。这样能看清哪一段最缺资源，而不必一次换掉整批奇波。

如果仍停产，按 **种子／原料→岗位能力→食物→计时→仓储与收取**查停止提示；没有读到明确原因前，先别继续扩建。

## 日本版寮与生产设施分开考虑

日本[正式上线公告](https://azurpromilia.jp/news/5225)中的農園「寮」用于角色交流：塗山小玉专用「春還る花亭」售至**2027年1月5日04:59 JST**，メーツァ专用「翠緑の秘苑」常驻销售。装饰、睡衣和头像等套装内容不构成生产加成或必购前置的依据。

家园尚未开放时，按当前主线和锁定条件继续[新手入门](/zh-hans/guides/getting-started/)；已经开放，就先完成一条“需求→原料→加工→交付”的产线，再逐步扩充。

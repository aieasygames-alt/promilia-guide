## 官方正文已经说明什么

中国大陆官网2026年11月20日《公测福利资源获取一览》正文写明：**登录即送66抽，探索与任务累计可得510抽以上，完成指定任务可免费获得五星角色与五星灵子**。

这几项是不同口径。正文没有证明所有资源在创建角色后一次到账，也不能把66与510直接相加；具体领取门槛、票券用途与活动期限需要继续核对图片细则和活动条款。此处不作为日本地区奖励依据。

## 领取前保留这些记录

| 记录项 | 为什么要记录 |
| --- | --- |
| 地区与版本 | 奖励条款可能按地区或活动不同 |
| 来源与活动名 | 避免把预约展示、登录奖励与长期任务混为一类 |
| 领取条件 | 记录账号、角色、任务和等级门槛 |
| 道具用途 | 确认票券对应的卡池，不提前换算为限定抽数 |
| 期限与时区 | 记录领取窗口及道具是否到期 |

## 暂不提供哪些资源结论

当前没有足够证据发布主线消耗体力、四人队伍成本、装备词条刷取等级、奇波离线产出效率或特定捕捉道具名称。已有的其他游戏经验不能替代本作正式服规则。

## 一个可复用的使用判断

作为编辑建议，每次消耗稀缺资源前先确认用途、获得方式和替代方案；涉及抽卡、自选、强化等决定时，先读当前客户端与对应活动条款。尚不能确认的项目放入[准备清单](/zh-hans/guides/getting-started/)，或查看[抽卡规则核验项](/zh-hans/guides/banner-rules/)。

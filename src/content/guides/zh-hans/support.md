## 先选地区和问题，再找客服入口

**国服可按“主页面 → 设置 → 账户 → 用户中心 → 联系客服”反馈；进不了游戏时，从国服官网“客服中心”进入。日本使用日本官网 FAQ／咨询入口，渠道账号问题联系对应渠道客服。** 国服菜单来自[公测FAQ第6节](https://azurpromilia.manjuu.com/home/news/detail/912070871064121344/)，官方同时注明以游戏内实际入口为准；本轮没有登录游戏或提交工单。

阅读本站中文或日文页面，不会改变游戏运营地区。先记下实际客户端、账号渠道和报错，再选下表入口；换设备也不代表换成了官方服账号。

| 你使用的地区／账号 | 官方说明的去处 | 先准备什么 |
| --- | --- | --- |
| 中国大陆官方服，能进入游戏 | 主页面 → 设置 → 账户 → 用户中心 → 联系客服；以当前入口为准 | UID、设备型号、系统版本、问题描述和相关截图 |
| 中国大陆官方服，无法进入游戏 | 从[国服官网](https://azurpromilia.manjuu.com/home/)进入“客服中心” | 卡住的阶段、错误原文、平台；拿不到UID时如实写未取得 |
| 中国大陆渠道账号问题 | 对应渠道客服；公测返还仍需原渠道账号与对应客户端 | 原参与渠道、客户端来源、账号问题；别把新账号当原测试账号 |
| 日本版 | [日本官网FAQ／お問い合わせ](https://azurpromilia.jp/contact)，或游戏内咨询入口 | UID、机型、OS、问题、发生时间与截图；咨询使用日语 |
| 尚未确定地区或客户端来源 | 先核对[地区与官方入口](/zh-hans/guides/global-release/) | 先确认运营方和应用，不把日本窗口当所有地区共用客服 |

国服“渠道账号问题找渠道”不等于所有战斗、画面或性能问题都只能找渠道；应按当前客户端提供的游戏客服与问题类别处理。本站[纠错与反馈](/zh-hans/contact/)用于整理站点内容错误，不能受理游戏账号、恢复角色或代发奖励。

## 进不去游戏：先区分四个阶段

| 停在哪里 | 先核对什么 | 怎样继续 |
| --- | --- | --- |
| 启动器、本体或增量资源 | 具体阶段、目标磁盘、报错，及本地区对应的重启对象 | 按[下载排查](/zh-hans/guides/download/)执行单项建议，记录结果 |
| 已到登录画面，但服务器未开放／维护 | 本地区最新服务公告与显示时间 | 用[开服说明](/zh-hans/guides/launch/)核对；预下载完成不代表能登录 |
| 国服显示实名要求或认证异常 | 当前官方认证提示；FAQ明确完成实名认证后方可登录 | 依官方界面处理，异常从官方或对应渠道求助；不自行猜失败原因 |
| 已进角色，但邮件／活动／功能锁定 | 当前任务、解锁提示、奖励来源、参与账号 | 按[领取条件](/zh-hans/guides/resources/)或对应系统指南核对前置 |

国服FAQ第1节只确认登录前需实名认证、未成年人限制按规定执行，没有在该条公布完整认证操作、失败原因或处理时限。不能由此承诺改绑、重建或换设备能解决，也不将该条套用于日本版。

日本PC校验失败的官方建议是重启**启动器**，国服相应条款写重启**客户端**。游玩中闪退又是先重启**设备**。反馈时写明实际重启了什么；只写“已经重启很多次”，客服仍难以知道失败发生在哪一层。

## 描述一次具体失败，比写“玩不了”更有用

先用一条可复述的记录说明问题：**在哪个画面 → 做了什么 → 原本期望什么 → 实际出现什么**。再补地区、版本、时间和已经尝试的操作。下面是编辑提供的整理方法，不代表官方表单每个字段都必填。

| 信息 | 写法 | 尚未取得时 |
| --- | --- | --- |
| 地区、平台、渠道 | 例如“中国大陆／PC／原参与渠道”，按实际填写 | 先保存官网入口或商店应用名，不猜运营地区 |
| 游戏／启动器版本 | 转录当前显示的版本，各写一项 | 写“该画面未找到版本” |
| UID | 用当前游戏角色的UID；按官方表单要求提供 | 写“未能进入角色，UID未取得”，不用网页活动ID代替 |
| 设备与OS | 型号和系统版本；PC可补CPU、GPU、RAM | 只记能确认的字段，不凭外观猜配置 |
| 具体问题 | 场景、动作、报错原文、发生次数 | 没有错误码就写无错误码；界面文字照录 |
| 时间与时区 | 记一次具体日期和时间，注明UTC+8或JST等 | 不用“刚才”“昨晚”作为唯一时间 |
| 已试步骤 | 每次只列一个动作及前后结果 | 没试过就写未尝试，不勾选成功 |

截图优先保留报错、锁定提示和所处阶段。重现只能稳定发生一次，也可以如实写一次；不要为了凑次数反复消耗抽卡券、材料或删除账号。

### 反馈前可整理的说明模板

```text
地区／平台／渠道：
游戏版本／启动器版本：
UID（若未取得请说明）：
设备型号／OS：
发生日期时间／时区：
停止的画面或任务：
复现：进入哪里 → 做什么 → 出现什么：
预期结果／实际结果：
错误原文／相关截图说明：
尝试的操作1／结果：
尝试的操作2／结果：
每次发生还是偶发：
```

可用[中文故障记录表](/downloads/launch-troubleshooting-zh-hans.txt)离线整理。表格不会自动发送；确认内容后，在对应地区的官方入口提交。账号密码、验证码不属于这份说明的字段。

## 玩法卡点也要把“未解锁”和“异常”分开

| 问题 | 先留下的依据 | 对应指南 |
| --- | --- | --- |
| 家园没有产出 | 设施名、锁定提示、材料、岗位、计时和领取状态 | [家园起步](/zh-hans/systems/home/)；尚无已核验的正式版解锁等级或配方 |
| 找不到奇波或活动奖励 | 分清野外来源、预约邮件、巢穴背包；记录实际名称与参与账号 | [奇波获取](/zh-hans/systems/kibo/)；活动奖励不能证明野外点位 |
| 技能按下却未触发 | 技能原文、目标状态、资源提示、操作与失败画面 | [战斗排查](/zh-hans/systems/combat/)；没有倍率与元素证据时不归因于削弱 |
| 邮件有附件却没有权益 | 附件原名、领取状态、背包和使用条件 | [测试返还](/zh-hans/guides/recharge-return/)与[福利](/zh-hans/guides/resources/)；凭证领取和激活分开 |

如果当前页面明确写着任务前置，先核对前置；若条件满足、提示却不一致，再把差异和截图交给官方。本站仍未完成首日任务链、家园首次生产和野外捕获实测，不能替你确认游戏内状态。

## 日本咨询语言、回复与未收到回信

[日本官方咨询说明](https://azurpromilia.jp/contact)要求以**日语**咨询，回复至表单填写的邮箱，不提供电话支持。提交前核对可接收的邮箱及「@azurpromilia.jp」受信设置；没看到回复时先检查垃圾邮件与地址是否正确。官方说明混杂等情况可能导致等待，没有承诺固定回复小时数。

下列日语框架只用于整理事实，不是已提交的工单：

```text
利用地域・プラットフォーム：
ゲーム／ランチャーのバージョン：
UID（確認できない場合はその理由）：
端末名・OS：
発生日時・タイムゾーン：
発生画面・再現手順：
期待した結果／実際の結果：
エラー表示：
試した操作と結果：
関連画像の説明：
```

发送后，按官方页面的受理结果与后续要求补充资料。本站没有提交咨询、取得工单回执或确认客服响应时间；国服FAQ也没有在上述条款给出统一回复时限。

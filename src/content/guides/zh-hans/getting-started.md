## 新手先做什么？

**用准备长期游玩的账号进入正式客户端，跟随主线解锁功能；邮箱开放后领福利，观测开放后再决定抽卡。** 先处理限时领取和影响功能解锁的主线，探索与收集可以按自己的节奏安排。

| 你现在在哪一步 | 直接看这里 |
| --- | --- |
| 还没安装或选服 | [地区版本](/zh-hans/guides/global-release/) · [官方下载](/zh-hans/guides/download/) · [容量配置](/zh-hans/guides/requirements/) |
| 已经进游戏，想领福利 | [感谢礼、预约与巢穴奖励](/zh-hans/guides/resources/) |
| 准备第一次抽卡 | [新手池、限定池与票券](/zh-hans/guides/banner-rules/) |
| 想找每日、周常 | 见下方“每日和周常在哪里” |
| 家园不生产或捕获卡消耗太快 | [家园排查](/zh-hans/systems/home/) · [奇波与捕获卡](/zh-hans/systems/kibo/) |

本页提供入门安排与奖励条件；具体任务名、解锁等级和完成时间以所玩版本的任务提示为准。

## 创角前：用对账号，保留活动奖励

参加过巢穴探索网页活动的玩家，先确认活动账号。**国服探索奖励发给参加蛮啾通行证下首个创建的角色；日服发给参加Yostar ID下最初创建的角色。** 改用新账号前，请先看[首抽与账号奖励](/zh-hans/guides/reroll/)。

国服「旅迹测试」付费玩家需要原充值账号和对应渠道客户端，邮箱开放后领取返还，不能转给新账号。具体比例、凭证和期限见[测试充值返还](/zh-hans/guides/recharge-return/)。

同地区换设备通常无需另建账号：国服官方服同账号PC／Android／iOS／鸿蒙进度同步，部分渠道服与官方服不互通；日服同账号PC／Android／iOS共享进度。跨地区账号规则见[平台与互通](/zh-hans/guides/platforms/)。

## 进入游戏后：主线、邮箱、抽卡

1. **跟随当前主线和教程。** 功能未开放时先读锁定提示，再推进对应前置。
2. **邮箱开放后查看奖励。** 预约、感谢礼、巢穴、测试返还分开领，读清附件和有效期。国服预约福利包含艾妮丝、星彩·浮云和纯粹忆痕×20等。
3. **观测开放后分清票券。** 国服新手纯粹忆痕8张十连，30次内至少一名五星；角色限定用璀璨忆痕，灵子限定用析光忆痕，分别90／80次保证。日服新手使用無垢な痕跡8枚十连，30回内五星，限定也分别90／80回。详情见[卡池规则](/zh-hans/guides/banner-rules/)。
4. **查看正在开放的活动。** 优先处理自己能完成、且临近截止的奖励，其他内容随进度安排。首期活动与期限见[福利总览](/zh-hans/guides/resources/)。

累计宣传抽数包含签到、等级、主线和不同票券，不等于创角后立即能用的限定抽数。按背包内实际券种安排投入更准确。

新手三次十连要24张普通票；20张票够两次十连、剩4张，再补4张才够第三次。国服首次自选需要50次常驻角色观测，新手的30次不计入这50次。已拿到五星、想决定自选对象时，可看[按现有角色选择的候选表](/zh-hans/guides/reroll/#国服常驻五星自选选谁先看你已有谁)，以及[具体配队案例](/zh-hans/systems/combat/#国服公测配队案例先按已有角色组一队)。

## 每日和周常在哪里？

入口没出现时，先继续主线。[繁中玩家11月27日的进度记录](https://forum.gamer.com.tw/C.php?bsn=79865&snA=711)提到，打完主线中的野猪王后看到了每日和每周任务。这是繁中个人进度参考，国服与日服的准确解锁任务仍看各自界面。

使用韩国PC版的玩家可参考[这份社区清单](https://arca.live/b/azurpromilia/190508272)：

| 目标 | 韩国PC入口 |
| --- | --- |
| 委托、体力相关项目 | Esc右下「의뢰」，F4 |
| 每日／周常奖励 | F5，分别检查两页的领取状态 |
| 通行证任务 | F2，查看下方任务区 |
| 家园产物 | Esc中的家园总部，检查建筑、牧场和农场 |

以上按键来自韩国版，改键后请从Esc菜单查找。国服、日服菜单与重置时刻以本服显示为准。任务已完成时，也别漏看奖励是否已经领取。

## 每天时间少，优先做哪些？

建议先领**已经达成的奖励**，再看**即将到期的活动**，然后推进**挡住下一项功能的主线**。体力材料按当前培养需求选择，可延后的地图探索放在后面。

家园开放后，可以顺路看看种子、食物和产物：[家园指南](/zh-hans/systems/home/)整理了种子管理与缺粮排查。遇到捕获卡消耗过快，先看[奇波指南](/zh-hans/systems/kibo/)中的资源预算与道具说明，再决定是否继续。

## 登录或领奖卡住了怎么办？

| 问题 | 处理方法 |
| --- | --- |
| 校验、追加资源报错 | 按[地区下载排查](/zh-hans/guides/download/)处理 |
| 国服提示实名要求 | 在官方界面完成认证；渠道账号问题联系原渠道 |
| 邮箱或功能尚未开放 | 查看当前任务与锁定条件，继续对应主线 |
| 能开邮箱但没找到奖励 | 区分奖励来源、参与账号与期限，见[未到账排查](/zh-hans/guides/resources/) |
| 原角色不见或账号异常 | 确认地区、渠道、账号与服务器，再联系[官方客服](/zh-hans/guides/support/) |

需要离线整理奖励时，可下载[奖励核对表](/downloads/launch-rewards-zh-hans.txt)。下方清单只在当前浏览器保存勾选进度，换设备或清除浏览器数据后可能丢失。

## 一组兑换码需要确认什么

| 项目 | 核对内容 |
| --- | --- |
| 地区与版本 | 国服、日本与渠道专属范围分别核验 |
| 原始代码 | 逐字核对官方原文，保留大小写 |
| 奖励 | 道具名、数量和发放方式 |
| 有效期 | 开始与结束日期、小时及时区 |
| 兑换入口 | 官方网页或当前客户端实际操作路径 |
| 领取条件 | 等级、账号、角色和每账号次数 |

<div class="callout callout-tip"><div class="callout-title">复制前先看状态</div><p>已到期的记录不会提供领取按钮。复制成功只表示字符串已进入剪贴板，不能代表兑换成功。</p></div>

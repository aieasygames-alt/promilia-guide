## 云·蓝色星原在哪里玩？Mac可以玩吗？

**11月26日官方公告确认，《云·蓝色星原》Android、iOS及网页端正式上线；网页端限电脑使用，并分别推荐 Windows 与 macOS 浏览器。** 电脑入口是[官方云游戏网页](https://azurpromilia.manjuu.com/cloudgame)，移动端从[官方云游戏下载页](https://azurpromilia.manjuu.com/cloudgame/download)区分云游戏与完整客户端。

本页适合想在 Mac 上玩、手机容量不足，或准备先试云游戏的玩家。依据是[中国大陆官网当天公告](https://azurpromilia.manjuu.com/home/news/detail/912757675975118848/)，不是日本版云游戏公告，也不代表全球英语版上线。本站仅核对公开公告和入口，未登录、排队或实测延迟。

## 电脑网页与手机云客户端怎样选？

| 设备 | 官方公告支持的方式 | 公告推荐条件 |
| --- | --- | --- |
| Windows 电脑 | 云游戏网页 | Chrome、Firefox、Edge及Chromium内核浏览器，更新至最新版 |
| Mac／macOS | 云游戏网页 | Safari、Chrome、Firefox、Edge及Chromium内核浏览器，更新至最新版 |
| iPhone／iPad | iOS云游戏客户端 | iOS 15及以上 |
| Android手机／平板 | Android云游戏客户端 | Android 6.0及以上 |
| 手机浏览器 | 本次公告未列为网页端支持方式 | 公告明确网页端“仅PC”，手机应查看对应云客户端入口 |

公告的网页端说明同时列出了 macOS，因此这里的电脑网页入口包含 Mac；它**不等于原生Mac安装包**。本轮没有取得日本版云服务、原生Mac客户端、Steam或主机版本的新证据，原生版本与地区支持仍见[平台说明](/zh-hans/guides/platforms/)。

## 免费时长：首次600分钟、每日15分钟、上限600分钟

官方公告列出的时长规则如下，均针对《云·蓝色星原》：

| 项目 | 公告规则 | 使用时要分清 |
| --- | --- | --- |
| 首次登录 | 可领取600分钟免费时长 | 600分钟等于10小时，是时长额度，不是无限期免费游玩 |
| 每日登录 | 可获得15分钟免费时长 | 公告未给每日刷新时区或固定领取钟点 |
| 免费时长累积上限 | 600分钟 | 达到上限后无法继续累积，不是每天额外存600分钟 |

例如，假设领取前余额为590分钟、没有其他扣减或变化，当次15分钟额度在600分钟上限约束下最多增加10分钟。这是按公告上限作的算术示例，不是实际到账或计费顺序测试。余额已为600分钟时，继续登录不能让免费时长变成615分钟。

公告没有在本页展开排队是否扣时、断线是否继续计时、畅玩卡与免费时长的扣减先后、余额有效期或全部付费价格。使用前查看云平台当前规则，不能把这里的示例当作完整计费条款。可以下载[云游戏使用记录表](/downloads/cloud-gaming-zh-hans.txt)，记录开始前后余额与排队情况。

## 容量不足时，用云游戏前先检查什么？

1. **先选地区和账号。** 本页介绍中国大陆官网云入口。日本版Yostar ID、其他渠道角色和海外商店资格不能仅凭同名游戏推导互通；本次公告也没有给出跨地区迁移规则。
2. **选对安装方式。** 官方下载页同时显示完整客户端与云客户端。手机需要云版本时，核对下载区域标题；电脑按官方网页入口进入。不要把普通游戏安装包当作云客户端。
3. **分别看云与原生配置。** 云公告列出的iOS 15／Android 6.0不是完整游戏的最低配置。原生版建议空余容量、内存和显卡要求继续看[配置与容量表](/zh-hans/guides/requirements/)。官方只称云包体小，本次没有核实确切MB数或更新后的占用量。
4. **查看网络和排队提示。** 官方明确高峰可能排队较长，建议错峰。高画质、高帧率、低延迟是官方产品介绍，本站没有测得固定延迟、帧率或流量消耗；实际体验需在自己的网络上判断。
5. **开始前后记录余额。** 首次额度、每日领取、畅玩卡和排队提示分别截图或记时。出现异常时保留设备、系统、浏览器、发生时间与错误原文，再按[官方客服指南](/zh-hans/guides/support/)联系对应入口。

## 云游戏常见问题

### Mac可以直接安装Windows版吗？

本次确认的是官方公告推荐的macOS浏览器云玩法，不是Windows安装器可在Mac原生执行。Mac用户先核对电脑网页入口；不要把云支持改写成原生Mac客户端已经发布。

### 云游戏永久免费吗？每天都送10小时吗？

公告是首次登录600分钟、每日登录15分钟，免费累积上限600分钟。它没有承诺无限免费或每天重发10小时。具体余额和权益以当前云平台为准。

### 手机能直接开网页玩吗？

本次公告将网页端标注为“仅PC”，移动端分别给Android和iOS云客户端。网站能在手机打开不证明支持手机浏览器游玩，应从官方下载页选对应云客户端。

### 看到“正式上线”就代表一定不用排队、一定能登录吗？

不能。官方已公告云服务上线，同时提醒高峰排队。本页没有测试登录或角色进度，也不保证账号资格、即时容量或网络体验。先检查官方当前状态，再记录具体错误，避免将排队问题当作普通客户端文件损坏。

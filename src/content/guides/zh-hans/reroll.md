## 国服常驻五星自选选谁？先看你已有谁

**先看已经抽到的随机五星和现成队友，再用自选补缺口。** 自选的50次门槛、后续200次循环，与池内随机五星是两套概念；具体次数和票券预算见[常驻自选规则](/zh-hans/guides/banner-rules/#国服常驻自选50次250次450次分别是什么)。新手池若还有计划要抽的次数，可以先看结果，再决定自选对象，避免两边都按同一个预想角色投入材料。

下面采用[带侠虎11月27日公测文章](https://news.17173.com/content/11272026/112816971.shtml)提出的配队方向，作为国服选择候选；本站按已有角色重新整理取舍。**这是作者建议，未独立验证队伍所需的等级、定弦、装备与奇波，也不保证关卡成绩。** 原文配图含测试版水印，这里只取作者的开服配队思路，不据此认定正式服技能效果。

| 你已有的角色／目标 | 自选方向 |
| --- | --- |
| 缺五星输出，已有米蒂 | 末音：作者组合为末音＋星临者＋米蒂 |
| 红宝石、法兰塔中已有一位 | 考虑补另一位；第三位可用米蒂或星临者 |
| 夏儿、阿比、璐璐卡中已有两位 | 考虑补齐缺少的一位 |
| 只有夏儿，缺另外两位五星队友 | 先考虑已有的卡塔露、艾妮丝过渡，再决定自选 |
| 已有涂山小玉，想围绕她组队 | 米砂是作者候选；也可先比较已有星临者、莉莉／枫糖的方案 |

末音方案只需一位五星，但仍需对应队友。夏儿的三五星方案若缺两人，一次自选也补不齐；四星过渡不保证效果等同。表格不覆盖全部十名常驻五星，也不按强弱排序。角色名单与可选范围以[国服官方公示](https://azurpromilia.manjuu.com/home/news/detail/912772234182004736)及游戏内自选界面为准。**佩佩在官方五星常驻名单中**；不要因为个别攻略没有推荐她，就误以为已退池。源千代的官网介绍也不能证明当前已经可抽取。

## 材料有限，选完后先培养谁？

选定一个当前要玩的组合后，先围绕这队投入，不要同时给表中所有候选备料。可按下面顺序安排；这是控制投入范围的编辑建议，不是角色最优加点或等级表。

1. **先确定主要操控的输出角色。** 没有目标五星、但现有队伍能继续推进时，可以先继续游戏，不必为了表格立刻换队。
2. **把队友补到能完成所需动作。** 辅助先满足其技能的解锁与使用条件；遇到容易倒下的问题，再优先处理生存，而不是把所有角色同时拉到同一培养程度。
3. **卡点再决定下一笔投入。** 技能按不出、无法命中时先查[战斗排查与配队思路](/zh-hans/systems/combat/)；操作正常仍有问题，再围绕当前队伍处理培养，不因一次失败重练整队。

本页没有正式版技能倍率、逐级材料用量或奇波绑定条件。要看三组候选的搭配理由与过渡限制，可继续读[公测配队案例](/zh-hans/systems/combat/#国服公测配队案例先按已有角色组一队)。


## 要不要刷初始？先看原账号会失去什么

**已有巢穴奖励、测试充值返还或游戏进度时，先确认这些能否保留，再考虑重开。** 国服和日服都已公布新手30次内五星、限定角色90次和灵子／アニマ80次保证。保底次数本身不能说明重开更省时；本站尚无经过验证的账号重置流程与首抽耗时。

| 你的情况 | 建议先考虑 |
| --- | --- |
| 原账号参加过巢穴探索 | 奖励绑定参与账号的首个角色，先看[领取条件](/zh-hans/guides/resources/) |
| 国服旅迹测试期间付过费 | 返还只发原账号，不能转移；见[充值返还](/zh-hans/guides/recharge-return/) |
| 只是不满意一次十连 | 新手30次内五星；先核对尚余次数和票券，不必马上弃号 |
| 为限定角色考虑新账号 | 比较已有进度、实际限定票和目标池期限 |
| 准备删除日服账号 | 日本条款明确删除后无法恢复，误删也一样 |

## 新手与限定池，怎样影响开局选择？

国服新手池用纯粹忆痕，日服用無垢な痕跡，均为**8张票十连、累计30次内至少一名五星角色**。三次十连消耗24张票，计30次观测。新手池与限定池分别计数。

日服首登特典中的20张無垢な痕跡够做两次新手十连（用16张、余4张）；若要凑齐三次十连，还需再取得4张。这里算的是普通票，不是20次限定角色观测。

限定角色与灵子分别90／80次保证，同类限定池之间继承；获得对应限定五星后重新计数。想要涂山小玉与花之舞时，分别看两类资源与计数，不能把灵子历史加进角色池。

国服首期限定结束于**12月17日03:59（UTC+8）**，日服为**同日04:59（日本时间）**。概率、票券与继承详情见[卡池规则](/zh-hans/guides/banner-rules/)。

## 网页奖励和测试返还会跟着新账号走吗？

巢穴探索奖励的接收条件如下：

- 国服：参加活动的蛮啾通行证下首个创建的游戏角色。
- 日服：参加活动的Yostar ID最初创建的游戏角色。

重新安装游戏不会改变这些账号条件。国服测试充值返还还要求原充值账号与对应客户端，明确不支持跨账号转移。普通预约奖励、巢穴奖励和测试返还应分别判断，详见[福利领取](/zh-hans/guides/resources/)。

## 日服删除账号前要知道什么？

[日本利用规约第4条第6项](https://azurpromilia.jp/terms/user)说明，账号被删除后利用权消灭，即使误删也无法恢复。**不要把删号当作可随时撤回的首抽重置按钮。** 卸载游戏、退出登录与删除账号是不同操作。

忘记账号或登录异常时，先找[官方客服](/zh-hans/guides/support/)，无需先删号。

## 刷初始常见问题

### 游客登录或清缓存能重来吗？

目前没有可供本页引用的正式版通用重置方法。请先确认本服的账号与恢复规则，再操作账号数据。

### 预约奖励和兑换码能反复领取吗？

按各项活动的账号、角色与次数限制处理。日服官方码及输入方式见[兑换码指南](/zh-hans/guides/redeem-codes/)。

### 繁中版能照用国服或日服的重置方法吗？

各版本账号和活动规则不同。本页没有繁中版重置步骤，繁中玩家请使用[对应运营方入口](/zh-hans/guides/global-release/)。

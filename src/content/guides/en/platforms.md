## Does Azur Promilia have PC and mobile cross-save?

**Japan’s FAQ confirms shared progress on the same account across Windows PC, Android and iOS. Mainland China’s official service separately confirms PC, Android, iOS and HarmonyOS progress sharing, while some channel editions are isolated.** This does not establish cross-region transfers or universal sharing of paid currency.

Choose the regional edition and login identity before switching devices. An English guide does not change the game client’s language or publisher. If you still need to choose a service, compare [regional release information](/en/guides/global-release/) first.

## Platform support by edition

| Edition | Confirmed platform information | Account boundary |
| --- | --- | --- |
| Japan | Windows PC, Android and iOS; same-account progress | Use the same regional account; this is not a Japan–China transfer |
| China official service | PC, Android, iOS and HarmonyOS; same-account progress | Check official-service login and server identity |
| China channel editions | Compatibility and account rules need the channel’s details | The same phone number does not prove the same account or server |
| China cloud service | Separate PC browser and mobile-app routes | Cloud access does not create a Japan or global service account |

The [Japan launch FAQ](https://azurpromilia.jp/contact) and China’s separate FAQ are regional statements. Shared character progress should not be read as a blanket promise about every purchase, paid balance or platform-specific benefit. Read those terms on the device where you intend to buy.

## How to move from phone to PC without starting over

Before creating anything on the second device, compare your region, publisher, login method and account identifier. Use the intended account and inspect the server or character display. If the existing character is missing, check those details before creating another one; a matching phone number or display name is not sufficient proof of account identity.

Keep the original character identifier and screenshots of the relevant account display for support. Never share a password or one-time verification code. If the client is correct but progress still differs, use the [regional support guide](/en/guides/support/) with the two devices, login methods and expected character details.

## Official Windows launcher and installation

Japan provides a [PC download page](https://azurpromilia.jp/PCdownload). Follow the official Yostar launcher route, then the full game client and any additional resources requested. A small launcher file is not the full installed game. Use the [download guide](/en/guides/download/) for the correct regional entry and installation troubleshooting.

The regional FAQs recommend **at least 120GB free space on PC and 55GB on mobile**. Those are storage recommendations, not RAM requirements or measured download payloads. Check the drive actually selected for the game, and compare the operating system, processor, graphics and memory with the [requirements guide](/en/guides/requirements/).

China’s FAQ says the old **旅迹测试** client cannot update directly into the release client: uninstall that old test client and install the current official release. Removing old software is different from deleting a game account. Do not apply Japan’s irreversible account-deletion option as an installation repair.

## Is Azur Promilia on Steam or PS5?

The cited Japan and China launch FAQs do not announce a Steam, PS5 or PS4 release. Use the official Windows distribution route rather than treating a search result, wishlist concept or third-party listing as proof of a launch version. This is the scope of the current cited information, not a claim that these platforms will never be supported.

A familiar title or logo on a store page is not enough to establish the publisher, edition or compatibility. Follow the region’s official website when checking whether a new platform has been added. Historical beta device restrictions are also not automatically release rules.

## Can you play on a Mac?

China’s November 26 cloud notice recommends macOS browsers, including Safari, for its computer-browser route. That supports **China cloud browser play**, not a native Mac installer or Japan cloud availability. The same notice marks browser play as computer-only and provides separate mobile cloud apps.

See [China cloud gaming on Mac](/en/guides/cloud-gaming/) for the announced free-time conditions and supported cloud OS versions. Cloud requirements differ from the native full game, and a browser page loading does not prove an account can enter a stream. This site has not tested cloud login or cross-device gameplay.

## Which version should you install next?

If you already have a character, keep its regional account and check the matching client for your new device. If you are starting fresh, choose the service whose account, language and availability conditions fit you, then install from its official links. Keep purchases and web-event rewards tied to that decision: cross-save within a service does not move them between regional publishers.

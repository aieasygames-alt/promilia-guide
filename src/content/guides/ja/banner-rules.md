## 現時点の結論

以前の特番まとめを原文リンクで照合できないため、80連すり抜けなし、装備60連天井、初心者50連2割引、選択箱や無期限引き継ぎを正式仕様として案内しません。中国本土と日本の条件は、それぞれの公式根拠が必要です。

## ガチャ画面で確認する項目

| 項目 | 必要な原文 |
| --- | --- |
| 対象 | ガチャ名、地域、開催期間 |
| 確率 | 最高レアと対象キャラの確率、段階的な変化 |
| 天井 | 回数、確定対象、早期排出時のカウント |
| 引き継ぎ | 同時開催・次回開催・ガチャ種別の区分 |
| チケット | 対応ガチャ、変換、期限と自動変換 |
| 初心者・選択箱 | 入手条件、対象一覧、終了条件、期限 |

## 根拠がそろうまでの準備

編集上の提案として、使い道を決めていない貴重な資源は保留し、対象ガチャの全条件を読んでから判断できます。他作品の天井で予算を計算したり、特典の総量を直ちに限定ガチャへ使える回数と見なしたりしないでください。

[資源の確認](/ja/guides/resources/)と[サービス開始準備](/ja/guides/getting-started/)も参照できます。

## 利用地域と問題を確かめてから窓口へ

**日本版は[日本公式のFAQ・お問い合わせ](https://azurpromilia.jp/contact)、またはゲーム内の相談窓口へ。中国本土はゲーム内の「主页面 → 设置 → 账户 → 用户中心 → 联系客服」、入れない場合は公式サイトの「客服中心」が案内されています。** チャネルのアカウント問題は該当チャネルのサポートへ進みます。

中国本土のメニューは[正式サービスFAQ第6節](https://azurpromilia.manjuu.com/home/news/detail/912070871064121344/)に基づきます。表示が異なる場合は、現在のゲーム内の案内に従ってください。日本版は日本公式の窓口を使います。

サイトの表示言語を変えても、ゲームの運営地域は変わりません。利用中のクライアントと配布元、問題が起きた画面を確認してから選んでください。

| 利用地域・状態 | 公式が案内する窓口 | 先に整理する情報 |
| --- | --- | --- |
| 日本版 | [日本公式FAQ・お問い合わせ](https://azurpromilia.jp/contact)、またはゲーム内窓口 | UID、機種、OS、問題、日時、画像。受付言語は日本語 |
| 中国本土の公式サーバー・ゲームに入れる | 主页面 → 设置 → 账户 → 用户中心 → 联系客服。実際の入口を優先 | UID、機種、OS、問題の説明、関連画像 |
| 中国本土の公式サーバー・ゲームに入れない | [中国本土公式サイト](https://azurpromilia.manjuu.com/home/)の「客服中心」 | 停止段階、エラー原文、プラットフォーム。UID未取得ならその旨を記載 |
| 中国本土のチャネルのアカウント問題 | 該当チャネルのサポート | 元の参加チャネルとクライアント。別アカウントで置き換えない |
| 利用地域や取得元が分からない | [配信地域と公式入口](/ja/guides/global-release/)から確認 | 運営とアプリを確認し、日本窓口を全地域共通として使わない |

「チャネルのアカウント問題はチャネルへ」は、戦闘や性能の問題もすべて同じ窓口しか使えないという説明ではありません。現在のクライアントが案内するゲームの窓口と問題分類を確認します。当サイトの[修正・お問い合わせ](/ja/contact/)は記事の訂正メモを整理する機能で、ゲームのアカウント復旧や報酬の配布は扱えません。

## ゲームに入れない時は四つの段階に分ける

| 止まる段階 | 先に確認すること | 次の行動 |
| --- | --- | --- |
| ランチャー・本体・差分データ | 段階、保存先、エラー、その地域の再起動対象 | [ダウンロード対処](/ja/guides/download/)を一つずつ試し、結果を記録 |
| ログイン画面から進めない | 対象地域のメンテナンス告知とエラー表示 | [配信状況](/ja/guides/launch/)を確認。ダウンロードが済んでいてもメンテナンスや認証で入れない場合があります |
| 中国本土で実名認証を求められる | 現在の公式表示。FAQは認証後にログインできると説明 | 公式画面に従い、不明点は公式・該当チャネルへ。原因を推測しない |
| キャラクターには入れるがメールや機能がロック中 | 現在の任務、ロック表示、報酬元、参加アカウント | [受取条件](/ja/guides/resources/)か該当システムで前提を確認 |

中国本土FAQ第1節は実名認証と未成年者の制限を説明していますが、認証手順の全体、失敗原因、変更方法、処理時間はこの条項では確認できません。再作成・連携変更・端末変更で解決するとも、日本に同じ要件があるともしていません。

PCの検証エラーでは、日本FAQは**ランチャー**、中国本土FAQは**クライアント**の再起動を案内しています。プレイ中の強制終了はまず**端末**の再起動です。「何度も再起動した」だけでなく、対象と結果を分けて書くと状況を伝えやすくなります。

## 問い合わせには何を書けばいい？

**どの画面で → 何をしたか → 何を期待したか → 実際には何が出たか**を一度の出来事として整理します。地域、バージョン、日時、試した操作はその後に補います。以下は編集部の整理方法で、公式フォームの全項目が必須だという意味ではありません。

| 情報 | 記載の仕方 | 確認できない場合 |
| --- | --- | --- |
| 地域・プラットフォーム・チャネル | 実際に利用した地域とクライアント | 取得元・アプリ名を保存し、運営を推測しない |
| ゲーム・ランチャーの版 | 表示されるバージョンをそれぞれ転記 | その画面では確認できないと記載 |
| UID | 現在のゲームキャラクターのUIDを、公式の要求に従い提供 | 入れず未取得と説明。WebイベントのIDで代用しない |
| 機種・OS | 機種名・型番とOS。PCは必要に応じCPU・GPU・RAMも補足 | 分かる項目だけ記載し、外観から推定しない |
| 問題 | 場面、操作、エラー原文、発生回数 | コードがなければコードなしと記載 |
| 日時・タイムゾーン | 一回の具体的な日時とJST・UTC+8など | 「先ほど」「昨夜」だけにしない |
| 試した操作 | 一つの操作と、その前後の結果 | 未実施は未実施のまま残す |

画像はエラー、ロック表示、どの段階かが分かるものを用意します。一度しか起きていなくてもその通り記載できます。回数を増やすためにガチャ券や素材を消費したり、アカウントを削除したりする必要はありません。

### 問い合わせ前の日本語テンプレート

```text
利用地域・プラットフォーム・チャネル：
ゲーム／ランチャーのバージョン：
UID（確認できない場合はその理由）：
端末名・OS：
発生日時・タイムゾーン：
発生画面・任務：
再現手順：どこへ → 何をする → 何が出る：
期待した結果／実際の結果：
エラー表示・関連画像の説明：
試した操作1／結果：
試した操作2／結果：
毎回発生するか・一度だけか：
```

[日本語のトラブル記録シート](/downloads/launch-troubleshooting-ja.txt)をオフラインでも使えます。記入だけでは送信されません。内容を確認して、該当地域の公式窓口へ提供してください。パスワードや認証コードはこの説明の項目に含めていません。

## システムのロックと不具合も区別する

| 困っていること | 先に残す情報 | 詳細 |
| --- | --- | --- |
| 農園で何も生産されない | 施設名、ロック、材料、配置、時間、受取状態 | [農園](/ja/systems/home/)。正式版の解放レベル・レシピは未検証 |
| キボやイベント報酬が見つからない | 野外の入手、事前登録メール、探索バッグを分け、名前と参加アカウントを確認 | [キボの入手](/ja/systems/kibo/)。イベント報酬から捕獲地点を推定しない |
| スキルのボタンを押しても発動しない | スキルの説明、対象、リソース表示、操作と発動しなかった画面 | [戦闘の確認](/ja/systems/combat/)で操作と発動条件を確認 |
| 添付は受け取れたが権利が有効にならない | 添付の原名、受取状態、バッグ、使用条件 | [中国本土の課金返還](/ja/guides/recharge-return/)と[報酬](/ja/guides/resources/)。証票の受取と有効化を分ける |

任務などの前提が明示されていれば、まずその条件を確認します。満たしているのに表示と一致しない場合は、相違点と画像を公式へ。

## 日本の受付言語・返信・返事が見つからない時

[日本公式の相談案内](https://azurpromilia.jp/contact)は**日本語**での受付、入力メールアドレスへの返信を説明し、電話サポートはありません。受信可能なアドレスと「@azurpromilia.jp」の受信設定を確認し、返信が見つからなければ迷惑メールや入力先も確認します。混雑などで時間がかかる場合があり、固定の回答時間は示していません。

中国本土への説明を整理する場合は、次の中国語項目も使えます。これは送信済みの問い合わせではありません。

```text
地区／平台／渠道：
游戏版本／启动器版本：
UID（若未取得请说明）：
设备型号／OS：
发生日期时间／时区：
停止画面／复现步骤：
预期结果／实际结果：
错误原文：
尝试的操作与结果：
相关截图说明：
```

送信後は公式画面の受付結果と追加依頼を確認します。中国本土FAQの上記条項にも統一した返信期限は記載されていません。

## 中国本土の初回DL最適化は進行中

[11月27日中国本土公式](https://www.taptap.cn/moment/875477210155189543)は大容量資源・回線変動時の一部iOS端末のDL・検証待ち、進行停止、ログイン画面での再検証を案内。資源分割・検証・中断再開を調整し、iOS優先で段階配布する方針です。**修正完了の発表ではありません。**

本体・追加データ・検証・ログインの停止段階、端末、バージョン、表示と時刻を記録し、対象版のFAQとサポートへ。日本版にも同じ問題があるとは推定せず、この告知だけで取得済みデータを繰り返し削除しないでください。中国本土の[クラウド版](/ja/guides/cloud-gaming/)は回線・アカウント条件を別に確認します。

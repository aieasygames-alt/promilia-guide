## まず再現できる戦闘を一回記録する

現在、引用できる正式版の戦闘実録がないため、元素相性表、ダメージ倍率、最適編成を推測で掲載していません。それでも一回分の観察はできます。現在のクライアントに表示されるチュートリアルを開き、地域、バージョン、場面を控えてから、以下の順で成功と発動しなかった結果を記録します。

このページは「次に何を確認するか」を整理するもので、ゲーム内チュートリアルの説明を置き換えません。ゲーム内の名称、ボタン、条件が変わった場合は現在のクライアントを優先し、スクリーンショットや動画の時刻を残してください。

## 初回の記録手順

1. **場面を固定する**：サーバーまたは地域、クライアントのバージョン、任務、キャラクター、装備、パートナーを控えます。別の敵や場面とは先に比較しません。
2. **表示を読む**：操作名、入力方法、対象条件、距離や範囲、エネルギー・クールダウンなどの表示を記録します。説明がない項目は「未確認」とします。
3. **基準を一回取る**：設定を変えずに操作し、対象の状態、画面の表示、結果を記録します。成功しても、発動条件がすべて分かったとは限りません。
4. **一つだけ変える**：二回目は対象までの距離、状態、キャラクター、パートナー、設定のうち一つだけを変えます。
5. **結果を残す**：成功、失敗、発動しなかった例をすべて保存します。成功場面だけでは、偶然の結果を安定した仕様と誤認します。

記録は次の形にすると、同じバージョンの資料と照合しやすくなります。

```text
地域 / バージョン：
場面 / 任務：
キャラクター / 装備 / パートナー：
操作と対象条件：
資源、クールダウン、表示：
結果：成功 / 失敗 / 発動しない
動画または画像の時刻：
試行回数と唯一の変更点：
```

## 発動しないときの確認順

チュートリアルの完了、任務の特別条件、操作設定、対象との距離や範囲、キャラクター・装備の条件、資源やクールダウンの順に確認します。一度に一項目だけを確認し、「発動しなかった」ことも有効な記録として残します。

一回の失敗だけで弱体化と判断したり、画質、キャラクター、装備を同時に変更した結果を元素の仕様と結びつけたりしないでください。同じ場面に戻り、基準の操作をやり直します。

## 元素の説明に必要な根拠

元素の名称、発動順序、対象、持続時間、例外を掲載するには、ゲーム内チュートリアル、現在のバージョンで繰り返せる記録、または確認可能な公式・公開テスト資料が必要です。似た色の演出だけでは、同じ反応が起きたとは判断できません。

相性表を先に作らず、次の五つの項目で整理します。

| 項目 | 確認する内容 |
| --- | --- |
| 名称 | クライアントや公式原文の名称。未確認の訳語は原語を併記 |
| 発動 | 順序、操作、対象条件、資源条件 |
| 効果 | 対象、持続時間、重ね掛けや解除の可否 |
| 範囲 | 地域、バージョン、テスト版/正式版、場面 |
| 例外 | 発動しない、耐性、無効、チュートリアルと異なる結果 |

過去のテスト表にはバージョンを明記します。繰り返し成功しても、正式版に引き継がれたとは自動的に判断しません。

## 今は結論にしないこと

対応する根拠がない段階では、具体的なダメージ倍率、元素相性表、最適編成、資源コスト、ガチャの効率や「必須」といった結論を公開しません。過去のテスト画像、別作品の経験、一回だけの高いダメージは現在のバージョンの記録の代わりになりません。

記録ができたら、[サービス開始前の準備チェックリスト](/ja/guides/getting-started/)で地域とクライアント情報を整理できます。端末や入力の問題は[端末の準備](/ja/guides/requirements/)を確認してください。正式チュートリアルや公開実録が追加された場合は、バージョンを更新し、中国語・日本語を一緒に再確認します。

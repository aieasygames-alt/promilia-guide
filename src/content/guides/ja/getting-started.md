## 始めたばかりなら何をする？

**使い続けるアカウントでログインし、メインストーリーとチュートリアルを進めましょう。** メールが使えるようになったら特典を受け取り、観測が解放されたらチケットの種類を確認してからガチャを引きます。

| 今知りたいこと | 案内先 |
| --- | --- |
| インストール・対応機種 | [ダウンロード](/ja/guides/download/) · [容量と動作環境](/ja/guides/requirements/) |
| 初回特典が欲しい | [事前登録・感謝特典と巣穴報酬](/ja/guides/resources/) |
| 初めてガチャを引く | [天井・チケット・開催期間](/ja/guides/banner-rules/) |
| デイリー・ウィークリーを探している | 下の「デイリーやウィークリーが見つからない」へ |
| 農園やキボで困っている | [農園と生産](/ja/systems/home/) · [キボの入手と用途](/ja/systems/kibo/) |

このページは序盤の進め方と特典の案内です。任務名、解放レベル、所要時間はプレイ中の表示を確認してください。

## キャラ作成前に、イベント参加IDを確認

「集まれ！キボの巣穴探索」の獲得報酬は、**参加したYostar IDで最初に作ったキャラクター**に配布されます。イベントに参加済みなら、ログインするIDを先に確認しましょう。詳細は[特典の受け取り方](/ja/guides/resources/)へ。

日本FAQでは同じアカウントでPC・Android・iOSの進行状況を共有できます。端末を変えるだけなら新しいアカウントを作る必要はありません。地域間の移行や有料通貨の扱いは[対応端末とデータ共有](/ja/guides/platforms/)をご覧ください。

リセマラを考えている場合は、先に[アカウントと報酬への影響](/ja/guides/reroll/)を確認してください。日本の利用規約では、誤って削除したアカウントも復元できないと説明されています。

## ログイン後はメインストーリー、メール、観測の順に

1. **現在の任務とチュートリアルを進める。** 使えない機能はロック表示の条件を確認します。
2. **メールで特典を受け取る。** 事前登録特典にはアニス、無垢な痕跡×20などがあります。感謝特典と巣穴探索報酬は別のメール・条件で確認してください。
3. **ガチャごとのチケットを確認する。** 始源の観測は無垢な痕跡8枚で10回、30回以内に星5キャラを保証。限定キャラは90回、限定アニマは80回が上限で、それぞれ次回の同種ガチャへ回数を引き継ぎます。詳しくは[ガチャガイド](/ja/guides/banner-rules/)へ。
4. **開催中のイベントを見る。** 自分が参加でき、期限が近いものから進めます。塗山小玉の初回ストーリーイベントと報酬は[イベント・特典一覧](/ja/guides/resources/)にまとめています。

ログインや指定任務を含む累計の観測機会と、初回ログイン時に持っている限定チケットは別です。所持品と対象ガチャを見ながら使い道を決めましょう。

日本の初回特典20枚で初心者10連を2回行うと、消費16枚・残り4枚です。3回目の10連にはさらに4枚必要になります。まず手持ちを見てから次の投入を決めましょう。[初回ガチャとアカウントの判断](/ja/guides/reroll/)では日本版の条件を先に、中国本土の恒常選択候補を別節で案内しています。

## デイリーやウィークリーが見つからない

入口がない場合は、まずメインストーリーと機能のロック表示を確認してください。[繁体字版のプレイヤー記録](https://forum.gamer.com.tw/C.php?bsn=79865&snA=711)では、メインストーリーのイノシシのボスを倒した後に毎日・毎週任務が表示されたと報告されています。日本版の正確な解放クエストを示すものではありません。

韓国PC版を遊んでいる場合は、[韓国のコミュニティ記事](https://arca.live/b/azurpromilia/190508272)に次の入口が載っています。

| 目的 | 韓国PC版の入口 |
| --- | --- |
| 委託・スタミナ関連 | Esc右下「의뢰」、F4 |
| デイリー・ウィークリー報酬 | F5、両方のページを確認 |
| パス任務 | F2、下部の任務欄 |
| 農園の回収 | Escから農園の本部へ |

この表は韓国版の参考です。日本版のキーやメニュー名、更新時刻はゲーム内で確認してください。キーを変更済みならEscメニューから探すと確実です。任務完了後は受取ボタンも忘れずに確認しましょう。

## 遊べる時間が少ない日は？

おすすめの順番は、**達成済み報酬の受取→期限の近いイベント→機能解放に必要なメインストーリー→自由な探索**です。スタミナの使い道は、今育てたいキャラに必要な素材から選んでください。

農園が使えるなら、種・食料・生産物を確認すると次の作業につなげやすくなります。[農園ガイド](/ja/systems/home/)には地域別の画面参考と食料不足の確認方法を掲載しています。捕獲用カードを使い続けるか迷ったら、[キボガイド](/ja/systems/kibo/)で用途や消費前の確認点を読めます。

## ログインや受取で困ったら

| 問題 | 確認先 |
| --- | --- |
| 検証エラー・追加データの失敗 | [ダウンロードの対処法](/ja/guides/download/) |
| メールや機能が使えない | 現在の任務とロック条件 |
| メールはあるが欲しい特典がない | [報酬の種類と未着の確認](/ja/guides/resources/) |
| キャラが見つからない・アカウント異常 | ID、地域、サーバーを確認して[公式サポート](/ja/guides/support/)へ |

中国本土版では実名認証やチャネルアカウント、テスト課金返還などの条件が異なります。[地域別ガイド](/ja/guides/global-release/)で利用するバージョンを確認してください。

必要なら[報酬チェックシート](/downloads/launch-rewards-ja.txt)を利用できます。下のチェックリストは現在のブラウザーに保存されます。別の端末やデータ消去後には引き継がれない場合があります。

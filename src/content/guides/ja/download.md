## 公式ダウンロードはどこ？PCは日本公式Windowsページへ

**日本公式は11月24日16:00、中国本土公式は同日15:00（UTC+8）の事前DL開始を、それぞれ発表しました。** 日本PCは[公式Windowsダウンロードページ](https://azurpromilia.jp/PCdownload)へ進みます。本体後には追加データが必要で、事前DLだけで先行プレイはできません。

[日本](https://azurpromilia.jp/news/5225)と[中国本土](https://azurpromilia.manjuu.com/home/news/detail/912762865511960576)は11月26日に開始を発表し、11月27日に確認済みです。現在のメンテナンス、個別アカウントのログイン可否、ファイル取得結果は分けて確認します。当サイトでは導入・ゲームログインを未実施です。

上の早見表は公式入口と、公式による事前DL開始発表を分けています。地域と端末を選んでください。記事の言語を変えてもゲームの地域は切り替わらず、JavaScriptが無効でも全端末の記録を読めます。

## 導入前のアカウント確認と4段階の完了条件

**地域、公式版か配布元別か、ログインID、保存先**を先に確認します。巣穴Webイベントの参加者はIDと最初のキャラへの配布条件を確認してから作成してください。[初回ログインの準備](/ja/guides/getting-started/)と[動作環境](/ja/guides/requirements/)に続きがあります。PCは対象ドライブに120GB以上、スマホは55GB以上の空き容量が推奨されています。

| 段階 | 完了の目安 | 止まった場合 |
| --- | --- | --- |
| 公式入口・日本PCランチャー | 対象地域のファイルまたはストアアプリを実際に取得 | URL・日時・エラーを保存。ページの閲覧だけで取得済みにしない |
| ゲーム本体 | 導入を終え、本体の起動や公式ランチャーの次の操作へ進める | 地域別の手順と保存先の空き容量を確認 |
| 追加データ | 現在のデータ取得・検証が終了し、版を記録 | 地域ごとの再試行・ランチャーまたはゲームの再起動を確認 |
| ログイン・キャラ | 予定したアカウントとキャラに入れる | メンテナンス・認証・配布元の問題は[公式窓口](/ja/guides/support/)へ |

入れたら[特典の受取条件](/ja/guides/resources/)と[ガチャの券種・保証](/ja/guides/banner-rules/)へ進みます。取得100%と特典の受取完了は別に確認してください。

## 日本PC・スマホのインストール手順

以下は公式FAQの案内です。当サイトが実機で完了した手順ではありません。

1. 日本向けクライアントと利用アカウントを確認します。PC・Android・iOSは同じアカウントで進行状況を共有できますが、他地域との共通アカウントを意味しません。
2. PCは[日本公式のWindowsダウンロードページ](https://azurpromilia.jp/PCdownload)からYostar公式ランチャーを取得し、ランチャーでゲーム本体をダウンロードします。スマホは日本公式から対象ストアへ進み、アプリIDと配信元を照合します。
3. PCは120GB以上、Android・iOSは55GB以上の空き容量を確保します。最低・推奨スペックとiPadの確認点は[容量・動作環境](/ja/guides/requirements/)へ。
4. 本体インストール後に起動し、画面の案内に従って追加データを取得します。サイズはその時点のクライアント表示を確認してください。
5. 日本公式は11月26日の正式サービス開始を発表済みです。現在のメンテナンスとアカウントの案内を確認してログインします。事前に取得したデータ全体を再ダウンロードする必要はありませんが、追加配信されたデータは案内に従います。

## 中国本土の本体・更新データ

こちらも中国本土FAQの案内で、今回の実機記録ではありません。

1. 公式サーバーかチャネル版かを確認します。公式サーバーは同一アカウントでPC・Android・iOS・鴻蒙の進行状況を共有しますが、一部チャネル版は公式と共有されません。
2. PCは120GB以上、スマホ・鴻蒙は55GB以上の空き容量を推奨。対応要件を確認してから取得します。
3. 対象の公式経路から現在の正式版クライアントを取得します。中国本土FAQは旧「旅迹测试」版を直接更新できず、完全にアンインストールして正式版を入れ直すよう説明しています。この案内を日本版や他のテストに一般化しません。
4. 本体インストール後に起動し、クライアント内で正式版の追加データを取得します。実際のサイズは画面の表示に従います。
5. 中国本土も11月26日の開始を発表済みです。現在のメンテナンスやログイン画面を確認します。実名認証など中国本土独自の条件も別途確認してください。

## ストアのサイズと推奨空き容量は別

Apple日本向けメタデータの配布サイズは3,644,462,080バイト（約3.64GB、十進表記）、中国区App Storeは3.9GBです。全ダウンロード量やインストール後の占有量ではありません。

FAQのスマホ55GB以上・PC120GB以上は推奨する空き容量です。ストアサイズに足したり固定倍率で換算したりせず、本体・追加データ・展開用一時領域・占有量を分けて確認します。

## 配信後に追加データを何度も取得する場合

11月27日に確認した[中国本土プレイヤーのTapTap投稿](https://www.taptap.cn/moment/875190460434352579)には、事前DL後も複数回の追加取得があったとあります。個人の記録であり、記載サイズを共通のパッチ容量や日本版の不具合にはできません。両地域のFAQは、本体導入後の追加データ取得自体を案内しています。

毎回同じ内容を取り直す場合は、ランチャーとゲームの版、各回のリソース名・容量、検証の完了、空き容量、導入先、エラー原文を記録します。同じ保存先を使っているか、取得と書込みが完了しているかを確認し、地域別FAQの再試行・再起動へ進んでください。新バージョンの追加データと、同じ版での検証失敗の繰り返しは別に報告します。公式の修正告知を確認できていないため、「修正済み」とは案内しません。

画面のカクつきは[動作環境とフレーム低下の確認](/ja/guides/requirements/)、継続する問題は[公式窓口への記録](/ja/guides/support/)へ。当サイトはパッチの再現・導入テストを実施していません。

## 中国本土の失敗対処：再起動の対象を日本と混同しない

以下は[中国本土の公測FAQ第5節](https://azurpromilia.manjuu.com/home/news/detail/912070871064121344/)の手順です。PCの検証エラーでは「クライアント」の再起動を案内しています。日本の「ランチャー」へ置き換えず、発生段階を確かめてから対応します。当サイトで修復を実測した結果ではありません。

| 中国本土版の症状 | 公式が案内する順序 | 改善しない時に残す情報 |
| --- | --- | --- |
| PCインストール・更新の容量不足 | **実際の保存先**の空きを確認。120GB以上を推奨し、不要ファイルの整理か保存先変更後に再試行 | 保存先、空き、エラー原文。他のドライブとの合計では判断しない |
| PCファイル検証エラー | 画面に従い再試行→**クライアント**再起動→未解決ならクライアントを再取得 | 操作ごとの結果と日時。最初から繰り返し入れ直さない |
| 起動時のリソース取得失敗 | **クライアント**再起動・再ダウンロード→未解決ならクライアントを再取得 | 本体か正式版の追加データか、停止画面とエラー |
| プレイ中に強制終了を繰り返す | 端末を再起動してゲーム起動。PCはPC再起動→続く場合はサポートへ | 機種、OS、発生日時、画像。起動前停止とプレイ中終了を分ける |

中国本土FAQにはセキュリティソフトのブロックに関する質問がありますが、具体的な解法は示されていません。日本FAQは取得元と警告の確認を案内しています。両者から保護の一括無効化という共通手順を作りません。

中国本土のゲーム内経路は「主页面→设置→账户→用户中心→联系客服」（実際の入口を優先）。入れない場合は公式サイトの「客服中心」、チャネルのアカウント問題は該当チャネルへ。[窓口の選び方と説明テンプレート](/ja/guides/support/)へ進めます。

## ダウンロード失敗・起動が遅い・強制終了の確認順

**まず、インストール・ファイル検証・追加データ・起動・ログインのどこで止まるかを確認します。** 日本FAQは症状ごとに対処を分けています。ランチャー、ゲーム、端末の再起動は対象が異なるため、該当する手順から試してください。次は[日本公式FAQ第4節](https://azurpromilia.jp/contact)に基づく案内で、当サイトによる修復の実測ではありません。中国本土版の手順へも流用しません。

| 止まる段階・症状 | 日本公式が案内する順序 | 解決しない場合 |
| --- | --- | --- |
| PCのインストール・更新で容量不足 | **実際のインストール先**の空きを確認。120GB以上を推奨。不要ファイルを整理するか、余裕のある別の保存先を指定 | 対象ドライブの空きと表示を記録。全ドライブの空きの合計では判断しない |
| PCダウンロードのファイル検証エラー | 画面に従って再ダウンロード。改善しなければ**ランチャー**を再起動して再試行 | エラーの内容を添えて公式サポートへ |
| 起動後の追加データ取得に失敗 | **ゲーム**を再起動して再ダウンロード。改善しなければ通信環境を確認して再試行 | 失敗した段階、エラー原文、日時を記録してサポートへ |
| PCの起動・読み込みが遅い | SSDにインストールしているか、保存先の空き容量が十分か確認 | [動作環境](/ja/guides/requirements/)と環境を照合。固定の読み込み秒数は未公表 |
| プレイ中に強制終了する | **端末**を再起動してからゲームを起動 | 繰り返す場合は機種、OS、発生日時、関連画像を添えてサポートへ |
| 本体・追加データ取得後もログインできない | 日本の開始・メンテナンス告知を確認し、サービス未開放とエラーを分ける | 正式サービス前はログイン不可。開始予定時刻を過ぎても現在の案内を確認する |

容量不足・ファイル検証の行はPC向けです。追加データと強制終了も、FAQの該当症状に合わせて使ってください。プレイへ進む前に止まっている場合は、単に「開かない」という理由でプレイ中の強制終了と断定せず、停止画面を残します。

### セキュリティソフトの警告は、保護を無効にすればよい？

公式FAQは、公式サイトから取得したファイルか、どのような警告かを確認し、解決しなければ警告が分かる画像を添えてサポートへ問い合わせるよう案内しています。**保護の無効化や一括除外を指示してはいません。** 特定エラーをドライバー、アンチチート、アカウント停止の問題と断定できる資料も、今回は確認していません。

### 事前DLしたデータを全部削除して入れ直す必要はある？

日本FAQ第2節は、事前DL済みデータをもう一度取得する必要はなく、新たな追加データがあれば画面に従うと説明しています。第4節の検証エラー時の再ダウンロードは、その症状への対処で、すべての問題に再インストールを求めるものではありません。中国本土の旧「旅迹测试」版の削除案内は、上記の地域・版に限る別の条件です。

## Mac・容量不足と中国本土のクラウド版

11月26日の[中国本土公式告知](https://azurpromilia.manjuu.com/home/news/detail/912757675975118848/)は「云·蓝色星原」の提供開始を案内しています。パソコンのブラウザにはmacOSも記載され、モバイルにはAndroid・iOSのクラウドアプリがあります。日本版のクラウド対応やネイティブMac版を発表したものではありません。

[中国本土クラウド版ガイド](/ja/guides/cloud-gaming/)で入口、初回600分・毎日15分・無料分の累積上限600分を確認できます。通常版の動作環境と別に読み、Yostar IDでの利用や日本のデータ引継ぎは推測しないでください。当サイトではログインと通信品質を未検証です。

## ゲームに入れない場合の公式問い合わせ先と記録

日本FAQ第5節はゲーム内「お問い合わせ」または[日本公式のサポートページ](https://azurpromilia.jp/contact)を案内しています。ゲームに入れない場合は公式サイトから進めます。ページでは問い合わせ種類を選んでからフォームへ進むため、実際の選択肢は現在の画面で確認してください。受付は**日本語**で、入力したメールアドレスへの返信となり、電話対応はありません。今回は公開窓口の確認のみで、問い合わせは送信していません。

公式フォームへ入力する前に、手元で次を整理すると状況を説明しやすくなります。

| 記録する情報 | 書き方 |
| --- | --- |
| 地域・プラットフォーム・ゲーム／ランチャーの版 | 例：日本PC。版は表示を転記し、見つからなければ未取得と記載 |
| UID・機種名・OSバージョン | UIDはFAQが案内する項目。入れず確認できない場合はその旨を記載し、事前登録やWebイベントのIDで代用しない |
| 問題と再現手順 | どの画面で何をすると何が出るか。エラー原文と、毎回かどうかを記録 |
| 発生日時・タイムゾーン | 「今晩」だけでなく、具体的な1回の日時を記載 |
| 試した操作と結果 | ランチャー・ゲーム・端末を分け、各操作の前後を記録 |
| 関連画像 | エラー、警告、発生段階が分かる画像。内容を確認して公式の案内に従って提供 |

[トラブル記録シート（TXT）](/downloads/launch-troubleshooting-ja.txt)をオフラインで使えます。JavaScriptは不要で、記入しても自動送信されません。パスワード、認証コード、ログイン情報は記入対象ではありません。

公式ページは受信可能なアドレス、迷惑メール設定、「@azurpromilia.jp」からの受信を確認するよう案内し、混雑などで返信に時間がかかる場合があると説明しています。固定の返信期限は示していません。中国本土・チャネル版は該当地域の公式窓口を使い、日本窓口を他地域共通のサポートとは扱わないでください。

## ダウンロードのよくある質問

### 鴻蒙版は早見表のAndroidを選べばよいですか？

中国本土FAQは鴻蒙を独立したプラットフォームとして記載しています。Androidリンクを鴻蒙用とみなしていません。日本FAQには鴻蒙の記載はありません。

### 繁体字版でも同じクライアントやアカウントを使えますか？

繁体字公式は独立したストア入口を案内しています。[地域・アプリIDの対照](/ja/guides/global-release/)を確認してください。今回の両地域FAQは、繁体字版の動作環境・時刻・地域間データ共有の根拠にはしていません。

## 追加データの数字・ファイル取得が気になる場合

日本の専用ページが案内するのはランチャーです。ランチャー、本体、差分データ、インストール後の占有量を別々に確認してください。今回、ファイルのHEAD取得は403でしたが、他の利用環境でも取得不能とは判断しません。公式ページから操作し、失敗する場合はエラーと日時を残して公式サポートへ。

両地域の開始公告は、追加資源が差分配信であることと、PCの追加資源が大きいことを説明しています。固定の追加GB数は掲載していません。120GB・55GBを追加資源の実測値に読み替えず、[容量表](/ja/guides/requirements/)とクライアント表示を分けて確認します。

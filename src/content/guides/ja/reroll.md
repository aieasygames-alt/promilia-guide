## リセマラする前に、元のアカウントを確認

**巣穴探索の報酬や進めたデータがあるなら、引き継げるかを先に確認しましょう。** 日本版は初心者30回以内の星5、限定キャラ90回、限定アニマ80回の保証を案内しています。天井の回数だけではリセマラの時間効率は決まりません。本ページでは、検証済みのリセット手順や最短所要時間は掲載していません。

| 今の状況 | 先に考えたいこと |
| --- | --- |
| 巣穴探索に参加済み | 参加Yostar IDで最初に作成したキャラへの配布条件 |
| 初回10連が希望どおりでない | 初心者30回保証までの残り回数とチケット |
| 限定キャラ目的でやり直したい | 現在の進行度、限定用チケット、開催期限 |
| 日本版のアカウントを削除したい | 誤って削除した場合も復元不可 |
| 中国本土のテストで課金した | 返還は元のアカウントのみ。別アカウントへ移せません |

## 初心者ガチャと限定ガチャの違い

日本の始源の観測は、**無垢な痕跡8枚で10回、累計30回以内に星5キャラを保証**します。3回の10連なら24枚を消費して30回。限定ガチャとは別のカウントです。

日本の初回特典「無垢な痕跡」20枚なら、初心者10連を2回行って16枚消費、残り4枚です。3回目には8枚必要なので、**さらに4枚**を入手する計算になります。20枚を限定キャラ20回分と数えないようにしましょう。

限定キャラは90回、限定アニマは80回が上限で、それぞれ次期の同種ガチャへ回数を引き継ぎます。キャラとアニマの履歴は合算できません。現在の対象は塗山小玉と花ノ舞、終了は**12月17日04:59（日本時間）**です。

ガチャごとの券種と詳しい条件は[天井・チケットのガイド](/ja/guides/banner-rules/)へ。初回特典の無垢な痕跡20枚を、限定20回分として計算しないようにしましょう。

## 巣穴探索の報酬は別のキャラへ移せる？

日本の巣穴探索イベントは、参加したYostar IDで**最初に作成したキャラクター**へ獲得報酬を配布します。インストールをやり直しても、この受取条件は変わりません。参加IDと受取先を[特典ガイド](/ja/guides/resources/)で確認してください。

中国本土版も探索報酬は参加アカウントの最初のキャラが対象です。さらに「旅迹测试」の課金返還は元の課金アカウントのみで、他のアカウントへの移行には対応していません。中国本土版の条件は[テスト課金返還](/ja/guides/recharge-return/)へ。

## アカウント削除は取り消せますか？

[日本の利用規約第4条第6項](https://azurpromilia.jp/terms/user)では、削除したアカウントは誤削除を含めて復元できないと説明しています。**削除を、いつでも戻せるやり直し操作として使わないでください。** アンインストール、ログアウト、アカウント削除はそれぞれ別の操作です。

ログイン不良やIDを忘れた場合は、まず[公式サポート](/ja/guides/support/)へ相談しましょう。

## 中国本土の恒常星5選択は誰を選ぶ？

**以下は中国本土版の編成案です。名前は中国語の公式表記を残しており、日本版のキャラ名や性能へ自動的に置き換えていません。** 中国本土の初回50回選択と、その後200回ごとの条件は[恒常選択の説明](/ja/guides/banner-rules/#中国本土の恒常星5選択累計50250450回)へ。日本版を遊んでいる方は、前節の日本向けチケット・特典・削除条件を基準にしてください。

まず獲得した星5とほかの仲間を見てから、足りない枠を選ぶと候補を絞れます。今後回す予定の初心者ガチャが残っているなら、その結果も踏まえて決めましょう。下表は[带侠虎氏の11月27日の公測記事](https://news.17173.com/content/11272026/112816971.shtml)を参考にした候補で、当サイトによる実戦検証・順位表ではありません。元記事の画像にはテスト版の表示があるため、正式版の性能を証明する資料とは扱っていません。

| 中国本土版の手持ち・目的 | 選択の方向 |
| --- | --- |
| メインの星5がおらず、米蒂がいる | 末音。作者案は末音＋星临者＋米蒂 |
| 红宝石か法兰塔がいる | 持っていない方を候補に。3枠目は米蒂または星临者 |
| 夏儿・阿比・璐璐卡のうち2人がいる | 残りの1人を候補に |
| 夏儿だけ所持 | 手持ちの卡塔露・艾妮丝でつないでから判断 |
| 涂山小玉を持っており、中心に遊びたい | 米砂を候補に。星临者、莉莉／枫糖を使う案も比較 |

末音の案は星5が1人ですが、ほかのメンバーも必要です。夏儿だけ所持している場合、1回の選択で3人組は完成しません。代役が同じ効果になる保証もありません。

育成段階・装備・定弦・キボの必要条件は独立確認できていません。全10名の優劣を決める表ではなく、今の手持ちで組める範囲を比べるためのものです。**佩佩は中国本土の公式星5恒常表に含まれます。** 紹介記事に編成が載っていないことと、排出対象外であることは別です。源千代の公式紹介も、現在ガチャで入手できる証明にはなりません。

## 育成素材が少ないときの進め方

育成先を一度に増やさず、まず使いたい編成を1組決めると素材を配分しやすくなります。以下は投入先を絞るための編集上の提案で、最適なスキル順やレベル表ではありません。

1. 主に操作するキャラを決める。今の編成で先へ進めるなら、すぐに全員を入れ替える必要はありません。
2. 編成メンバーは必要なスキルを解放して使える状態にする。倒れやすいときは生存面を先に見直し、全員を同じ育成段階へそろえることを目的にしないようにしましょう。
3. 詰まった原因に合わせて次の素材を使う。操作・命中の問題なら[戦闘の確認手順](/ja/systems/combat/)を先に確認できます。

中国本土の3つの組み合わせと、代役を使うときの考え方は[編成例の解説](/ja/systems/combat/#中国本土の公測編成例手持ちから1組を選ぶ)へ。日本版の検証済み最強編成を示すものではありません。

## リセマラのよくある質問

### ゲストログインやキャッシュ削除でやり直せる？

現在、本ページで案内できる正式版の共通リセット手順はありません。アカウントの連携・復旧条件を先に確認してください。

### 事前登録特典やコードは何度でも使える？

特典ごとのアカウント・キャラ・回数制限に従ってください。公式コードの入力は[コードガイド](/ja/guides/redeem-codes/)へ。

### 繁体字版にも同じ手順を使える？

運営元とアカウントの条件が異なります。繁体字版の手続きは[地域別の公式入口](/ja/guides/global-release/)から確認してください。

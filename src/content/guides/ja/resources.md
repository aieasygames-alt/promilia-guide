## 地域と受取条件から確認する

中国本土の特典案内と日本のWebイベントを分けて整理します。中国本土の11月20日公式本文には、ログイン66連、探索・任務で累計510連以上、指定任務で星5キャラと星5霊子を無料入手と記載されています。

66と510を単純合計したり、初日にすべて限定ガチャへ使える回数と考えたりしないでください。画像ではログイン、7日間のサインイン、レベル、メイン任務が分かれています。

## 中国本土：特典と必要な条件

次の名称は中国本土の原文表記です。日本向けの正式名称・配布内容とは別に扱います。記載は一部の報酬で、初日の合計ではありません。

| 入手元（中国語名） | 画像にある報酬 | 確認する条件 |
| --- | --- | --- |
| 予約・SNS達成報酬 | 「艾妮丝」「星彩·浮云」、纯粹忆痕×20など | ログイン受取。対象アカウント、入口、期限は当期の規約で確認 |
| 公测谢礼 | 璀璨忆痕×20、秘虹晶×1000 | ログイン後のメール受取。メール期限を確認 |
| 星临旅记 | 璀璨忆痕合計×10 | 7日間のサインインが必要。初回ログインの一括配布ではない |
| 来自星海的礼赠 | 纯粹忆痕×10、キャラ「诺诺」など | ログイン・サインイン。進捗と期限は個別に確認 |
| 星光初拾 | 析光忆痕×20、纯粹忆痕×50など | 指定の星識レベルに到達。合計から各段階の必要レベルを推測しない |
| 小小侠客养成记 | キャラ「佩佩」、霊子「修行中」、纯粹忆痕×6など | 指定任務を達成。星5選択報酬とは別の項目 |
| 星之旅录·启程 | 星5霊子選択×1、纯粹忆痕×40、秘虹晶×700など | 指定任務を達成。選択候補はアイテム説明で確認 |
| 新芽初萌之旅 | 纯粹忆痕合計×40 | メイン任務を進行・達成。ログインのみの報酬ではない |

公式の「登录就送」の集計にも7日間サインインが含まれます。メールで受け取った数だけで全特典の受取不足を判断せず、未達成の条件と受取済みの項目を照合してください。

## 期間限定・月次交換・恒常を分ける

| 公式画像の区分 | 例 | 読み方 |
| --- | --- | --- |
| 期間限定 | イベント、日次・週次活躍、星轨交換など | 開催期間、更新、受取条件を個別に確認 |
| 月次交換 | 星轨兑换 | 画像は毎月更新の2回分を集計。全額を毎月1回受け取れる意味ではない |
| 恒常入手 | 探索、メイン任務、実績、レベルなど | 解放・達成・受取の手順は個別に必要 |
| ホーム関連 | ホームレベルとホームショップに纯粹忆痕各×8 | 毎時の施設生産量でも、無償・無制限交換の証明でもない |

集計期間が十分に分からないため、固定の日収・月収には換算しません。継続収入は解放状況、更新時刻、チケット、有償・無償を分けて記録してください。

## 日本：「集まれ！キボの巣穴探索」の期限と配布先

日本公式サイトから案内される本イベントは、2026年11月20日21:00から12月31日13:00まで（日本時間）。参加にはYostar IDを使用します。

- 探索任務には事前登録、ダウンロード、別のWebイベントのプレイ、シェア、フレンドの協力があります。探索は最大9回で、毎回探索報酬1つと宝箱の鍵1個を獲得。最大9回ですべての探索報酬を入手できます。
- 11月24日16:00（日本時間）の事前ダウンロード開始予定後、ダウンロード任務が参加可能となり、事前登録任務は終了します。イベント全体の締切とは異なります。
- 探索報酬はバッグに保管され、正式サービス開始後にゲーム内メールで配布されます。配布先は参加Yostar IDで最初に作成したキャラクター。ゲームへの初回ログインから365日以内に受け取ります。
- 探索報酬にはキボ「星彩・キラミィ」などがあります。実物・ギフトカードは別の抽選であり、探索すれば必ず当たる報酬ではありません。

協力任務があるため、招待なしで全報酬を取れるとは案内しません。一方、このWebイベントから本編のマルチプレイやPvPが必須だと判断することもできません。キャラを作り直す前に配布先の条件を確認してください。

## 受け取った後に使い道を確認する

中国本土画像の「纯粹忆痕」「璀璨忆痕」「析光忆痕」は別の名称です。名前と枚数だけでは対象ガチャ、交換率、有効期限を確定できません。「秘虹晶」もここではガチャ回数に換算しません。

使用前にアイテム詳細と[ガチャの確認手順](/ja/guides/banner-rules/)を確認してください。進め方は[初日の準備](/ja/guides/getting-started/)、[ホーム入門](/ja/systems/home/)、[キボ入門](/ja/systems/kibo/)へ。

## 報酬が届かないとき

地域、イベント名、参加アカウント、配布先キャラ、任務達成、受取期間を確認し、「未達成」「受取操作済みで配布待ち」「メール未受取」を分けます。条件を満たしても異常がある場合は、規約と個人情報を隠した記録を添え、対象地域の公式窓口へ相談してください。

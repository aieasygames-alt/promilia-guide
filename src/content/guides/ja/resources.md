## 受け取りたい特典の種類から確認

| 見ている情報 | 先に確認する場所 | 受取完了の目安 |
| --- | --- | --- |
| コード文字列 | [コードの確認状況](/ja/guides/redeem-codes/)と各公式原文 | 公式の交換結果とアイテム増加。コピーだけでは完了しない |
| 登録・ログイン・レベル・任務の配布総量 | 対象地域のイベント・メール・任務条件 | 各条件を満たして受取。累計を初日の受取分にしない |
| キボの巣穴探索 | 同地域のWeb任務・探索バッグ・参加ID | 探索で獲得後、規約に従い最初のキャラのメールで受取 |

中国本土のログイン66連、探索・任務累計510連以上は、日本の特典とは分けて確認します。Web探索の登録任務は事前DL予定時刻で終了し、イベント全体の終了とゲーム内受取期限は別の日時です。

## 地域と受取条件から確認する

中国本土の特典案内と日本のWebイベントを分けて整理します。中国本土の11月20日公式本文には、ログイン66連、探索・任務で累計510連以上、指定任務で星5キャラと星5霊子を無料入手と記載されています。

66と510を単純合計したり、初日にすべて限定ガチャへ使える回数と考えたりしないでください。画像ではログイン、7日間のサインイン、レベル、メイン任務が分かれています。

## 中国本土：巣穴探索のWeb報酬を受け取る手順

[中国本土公式](https://azurpromilia.manjuu.com/)の「集结，勇闯奇波巢穴」から「活动规则」を確認できます。期間は2026年11月20日から12月31日12:00（UTC+8）。開始日の時刻は記載されていません。

1. 中国本土で使用予定の蛮啾通行证を確認して参加します。探索報酬の配布先は、このアカウントで最初に作成したゲームキャラクターです。
2. 任務の達成状態と探索回数を確認。本人の事前登録、ダウンロード、キボキャンプのプレイ、シェアは各1回。フレンド協力は最大6回、ダウンロード協力は最大3回です。
3. 獲得した回数で巣穴を探索。毎回、探索報酬1件と宝箱の鍵1個を必ず入手します。1人最大9回で、最大9回ですべての探索報酬がそろいます。
4. 「探索背包」で獲得済みアイテムを確認。回数の獲得、探索の実行、報酬の保管は別の進捗です。
5. 正式配信後、参加アカウントでゲームへ入り、最初に作ったキャラのゲーム内メールで受け取ります。期限はゲームへの初回ログインから365暦日以内で、イベント終了からではありません。

中国語原文の報酬は「星彩·小星喵」×1、纯粹忆痕×1が3セット、原初水滴×1、闪耀的星结卡×10、特级星赐启辉礼盒×1、纯澈的星脉结晶×5、尤尼×10000です。記載順が獲得順とは限りません。

11月24日15:00（UTC+8）の事前DL開始予定後、中国本土の規約では任務②～⑥が参加可能となり、①は終了すると記載。任務別の上限を足し合わせても、探索の総上限は9回です。

## フレンド協力のカウントを分ける

| 項目 | 中国本土・日本で各々確認した条件 |
| --- | --- |
| 招待した側の回数 | イベント協力1人につき1回、最大6回。DL協力1人につき1回、最大3回 |
| 他の人へのイベント協力 | 期間中、1人あたり最大8人を支援。自分の探索回数とは別 |
| 他の人へのDL協力 | 1人あたり最大1人を支援 |
| 両方への加算 | 専用DL協力リンクや共有画像からのDL完了は、イベント協力とDL協力の両方に加算 |
| 探索の総上限 | 1人最大9回。全任務の上限の単純合計や、招待不要の全回収は案内しない |

利用する地域の規約を確認してから共有を判断してください。通常のストアを開くだけでは専用リンクの協力完了を証明できません。実際の進捗を確認しましょう。当サイトでは招待の送信や個別アカウントの達成確認を行いません。

## 日本：「集まれ！キボの巣穴探索」の期限と配布先

日本公式サイトから案内される本イベントは、2026年11月20日21:00から12月31日13:00まで（日本時間）。参加にはYostar IDを使用します。

- 探索任務には事前登録、ダウンロード、別のWebイベントのプレイ、シェア、フレンドの協力があります。探索は最大9回で、毎回探索報酬1つと宝箱の鍵1個を獲得。最大9回ですべての探索報酬を入手できます。
- 11月24日16:00（日本時間）の事前ダウンロード開始予定後、ダウンロード任務が参加可能となり、事前登録任務は終了します。イベント全体の締切とは異なります。
- 探索報酬はバッグに保管され、正式サービス開始後にゲーム内メールで配布されます。配布先は参加Yostar IDで最初に作成したキャラクター。ゲームへの初回ログインから365日以内に受け取ります。
- 探索報酬にはキボ「星彩・キラミィ」などがあります。実物・ギフトカードは別の抽選であり、探索すれば必ず当たる報酬ではありません。

協力任務があるため、招待なしで全報酬を取れるとは案内しません。一方、このWebイベントから本編のマルチプレイやPvPが必須だと判断することもできません。キャラを作り直す前に配布先の条件を確認してください。

## 受け取った後に使い道を確認する

中国本土画像の「纯粹忆痕」「璀璨忆痕」「析光忆痕」は別の名称です。名前と枚数だけでは対象ガチャ、交換率、有効期限を確定できません。「秘虹晶」もここではガチャ回数に換算しません。

使用前にアイテム詳細と[ガチャの確認手順](/ja/guides/banner-rules/)を確認してください。進め方は[初日の準備](/ja/guides/getting-started/)、[ホーム入門](/ja/systems/home/)、[キボ入門](/ja/systems/kibo/)へ。

## 報酬が届かないとき

| 止まっている段階 | 確認すること | 次の行動 |
| --- | --- | --- |
| 任務後に回数が増えない | 同じ参加IDか、任務の開始・上限 | 任務文と現在のカウント、変化しない表示を記録 |
| 回数はあるがバッグにない | 探索を実行したか | 残り回数とバッグを確認。任務完了と報酬獲得を区別 |
| バッグにあるがメールがない | 正式配信後か、参加IDの最初のキャラか | IDと作成順を照合。正確な配布時刻は未確認 |
| メールはあるが所持品にない | 受取操作、添付とエラー | メール状態とアイテム名を確認。先にガチャ回数へ換算しない |
| ログイン・レベル特典が出ない | 対象イベント、日数、レベル、前提 | 個別規約を確認。Web報酬の365日を流用しない |

条件を満たしても異常がある場合は、イベント名、必要部分のみのID情報、キャラ、時刻・タイムゾーン、任務状態、エラーを対象地域の公式窓口に伝えます。中国本土は配信後の公式「联系客服」、日本は公式「FAQ」から案内されます。

[日本のお問い合わせ](https://azurpromilia.jp/contact)は日本語で受け付けています。受信できるメールアドレスと迷惑メール設定を確認してください。パスワードや認証コードは送らないでください。

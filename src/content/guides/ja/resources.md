## 公式本文で確認した範囲

中国本土公式の2026年11月20日「公測福利資源獲取一覧」には、**ログインで66連、探索と任務で累計510連以上、指定任務で星5キャラクターと星5霊子を無料入手**と記載されています。

それぞれ異なる区分です。キャラクター作成直後の一括受取や、66と510の単純合計は本文から確定できません。個別の画像細則と活動規約で受取条件、チケット用途、期限を照合する必要があります。日本向け報酬の根拠にはしません。

## 受取前に残す記録

| 項目 | 確認する理由 |
| --- | --- |
| 地域と版 | 活動・地域で条件が異なる可能性 |
| 出典と活動名 | 事前登録、ログイン、長期任務を区別 |
| 受取条件 | アカウント、キャラクター、任務、レベル |
| 用途 | 対応ガチャを確認し、限定ガチャ回数へ先に換算しない |
| 期限と時刻 | 受取可能期間と道具の期限 |

## まだ案内しないこと

メイン任務のスタミナ消費、4人編成の費用、装備厳選の推奨レベル、キボのオフライン生産効率や捕獲道具の固有名は、根拠不足のため案内しません。他作品の経験は正式版の仕様を証明しません。

## 消費前の判断手順

編集上の提案として、貴重な資源を使う前に用途、入手方法と代替策を確認してください。ガチャ、選択箱や強化は現在のクライアントと活動規約を先に読みます。不明点は[準備リスト](/ja/guides/getting-started/)へ記録し、[ガチャ確認項目](/ja/guides/banner-rules/)も参照できます。

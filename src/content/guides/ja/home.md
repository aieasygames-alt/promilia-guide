## 農園の生産が止まったら？

**種、食料、作業適性、保管上限の順に、画面の停止理由を確認しましょう。** 中国本土・韓国のプレイヤー投稿を地域別の参考として紹介し、日本版の寮については日本公式のお知らせを案内します。日本版の正確な解放レベルや自動生産効率は未検証です。

| 困っていること | 見直す場所 |
| --- | --- |
| 次の栽培が始まらない | 種の在庫・設定、種まき・水やり・収穫の担当 |
| 食料が足りない | 食料補給、在庫、配置数 |
| 配置したのに生産しない | 作業適性、材料、稼働・停止の表示 |
| 生産物が所持品に入らない | 保管上限と受取状態 |
| 農園自体が使えない | メイン任務とロックの条件 |

## 日本版の寮と販売期間

[日本の正式サービス開始告知](https://azurpromilia.jp/news/5225)では、農園に「寮」を置いてキャラと交流できると案内しています。塗山小玉専用「春還る花亭」は2027年1月5日04:59（日本時間）まで、メーツァ専用「翠緑の秘苑」は常設販売です。

装飾、寝間着、アイコンなどのセットで、生産効率のために購入が必須という案内ではありません。生産施設の解放条件とは分けて確認してください。

## 種の管理画面：韓国版の参考

[韓国プレイヤーHorolの11月27日の図解](https://arca.live/b/azurpromilia/190507810)には3枚の画面があります。流れは **農園の全体画面下部「키보 농장」→畑の右下「씨앗 관리」→「씨앗 창고」の種スロット**。韓国語の原表示であり、日本版のメニュー名や配置は異なる場合があります。

1. 農園が解放済みなら畑の入口へ。未解放なら現在のメイン任務とロック表示を確認します。
2. 種の管理を開き、在庫とスロットの設定を確認します。
3. 投稿の種倉庫には設定順に栽培する説明があります。必要な作物を設定したら畑に戻り、配置と食料も確認してください。
4. まず1回の種まき・作物の変化・回収を確認してから配置を増やします。自動稼働の効果は当サイトでは未検証です。収穫物を自動回収する切替と、種の設定は分けて確認します。

投稿者がレベル21で気づいたことは必要レベルの根拠にはなりません。15〜20分ごとに戻っていたという体験も全作物の生産周期ではありません。画面が異なる場合は自分の版の説明に従ってください。

## 中国本土の初日投稿：栽培・食卓・注文の確認から

11月26日の[TapTap投稿「家园1–15级规划」](https://www.taptap.cn/moment/875088587471717682)は、中国本土プレイヤーの雅中林阁が当日の体験を整理したものです。作者はテスト未参加と明記し、コメントでも補足・修正があります。当サイトで再現しておらず、日本版の解放レベル・配置の確定手順にはできません。

| 中国本土の投稿にある名称 | 投稿が示す操作の手掛かり | 自分の画面で確かめること |
| --- | --- | --- |
| 耕作小屋 | 播種・水やり・収穫の分担、種子管理 | 作業適性、種子在庫、稼働状態 |
| 种子管理 | 高い星数の種子を優先する選択肢 | 貴重な種子の用途と任務の要求 |
| 奇波餐桌 | 食料補充、「一键添加」の案内 | 素材、食料在庫、実際の消費 |
| 订单看板 | 注文の内容に合わせた生産 | 今必要な品と投入量 |

名称は中国本土の原文を残しています。日本版のメニュー名として翻訳対応を保証するものではありません。投稿にあるレベル・枠数を全ユーザー共通の解放条件にせず、今の任務とチュートリアルを優先してください。

## 配置を増やしたら食料不足？追加分の収支を見る

11月27日に確認した[食料消費の個別投稿](https://www.taptap.cn/moment/875286112719866850)は、配置を埋めると食料が不足し、一部の補助効果が消費に見合わないという内容です。完全な比較条件がないため、金色の特性全体が弱い、毎時の収益が一定、といった結論にはしません。

食料が減り続ける場合は、必要な生産を残し、食卓への補給と、今は使わない担当を見直すことを勧めます。補助担当を増やす前に、追加の生産量が食料消費に見合うかを確認しましょう。手動の補給・任務報酬・注文でも在庫は変わります。効率は配置によって異なり、共通の最適配置は未確認です。

## 生産が進まないときの確認順

施設の停止表示を読み、**材料と種→担当キボの適性→食料→経過時間→保管と受取**を確認します。担当を増やして食料が減り続けるなら、追加の配置を見直し、必要な生産を優先してみましょう。

キボのレアリティだけでは作業適性は決まりません。施設の要求と個体の能力を見比べてください。孵化や装備製作も、それぞれの前提と材料を確認してから進めます。

## 拡張とキャラ育成、どちらを先にする？

今不足しているものから考えると選びやすくなります。任務素材が足りないならその入手先を、農園レベルやショップの報酬が目的なら必要条件と交換費用を先に確認しましょう。

農園がまだ使えないときは[初心者ガイド](/ja/guides/getting-started/)、担当選びは[キボの用途](/ja/systems/kibo/)、受け取れる特典は[報酬一覧](/ja/guides/resources/)をご覧ください。

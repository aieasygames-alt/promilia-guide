## ホームで最初に解決したいこと

正式版の解放任務、施設操作、配置条件はまだ照合が完了していません。本ページでは報酬・生産・配置を分け、初回の解放と生産の記録を助けます。未検証の建築順や完成効率表は提示しません。

中国本土の11月20日特典画像は、恒常入手の区分でホームレベルとホームショップに中国語名「纯粹忆痕」各×8を掲載しています。ログイン配布、無償・無制限交換、施設の毎時生産量を示すものではありません。日本向けには別の確認が必要です。

## 報酬と生産を別々に見る

| 項目 | 最初の確認 | そのまま推測できないこと |
| --- | --- | --- |
| ホームレベル報酬 | 必要レベル、受取場所、受取済みか | 毎レベル同じ数がもらえる |
| ホームショップ | 通貨、在庫、更新、購入前提 | 公告の総数を無償で一括入手できる |
| 施設生産 | 材料、配置、時間、保管、受取操作 | 報酬表の数値が毎時収入になる |
| キボの配置 | 必要能力、配置状態、不足条件 | レアリティが高ければ常に最適 |

## 初回解放時の確認順

1. 現在の任務やロック表示で、任務名と前提を確認。他地域やテスト版のレベルで代用しません。
2. システムの説明を読み、最初に使える施設、用途、費用、操作場所を記録します。
3. キボの配置を求められたら必要能力を照合。能力の根拠がなければランキングだけで育成しません。
4. 開始前の在庫、投入、終了予定と、受取後の変化を比較。一度きりの任務報酬を継続生産に混ぜません。
5. 終了前に保管、計時、停止条件を確認。オフライン継続と上限は規約や再現記録で調べます。

確認の順序であり、正式版が必ずこの5段階で解放されるという意味ではありません。該当項目がない場合は現在の画面とバージョンを残し、推測で埋めないでください。

## 生産が進まないとき

解放完了、施設開始、材料、配置条件、経過時間、保管上限、手動受取の順に確認します。一度に変える条件を絞り、前後を記録。単独の結果から全施設のオフライン仕様を一般化しません。

| 記録 | 残す内容 |
| --- | --- |
| 地域・版・施設 | 画面の正式名称 |
| 任務と配置前提 | 表示条件と達成状況 |
| キボと能力 | ゲーム内の原文 |
| 投入・時間・生産 | 開始前、終了時、受取後を分ける |
| 停止理由 | 満杯、材料、配置、未解放、未特定 |

## 拡張とキャラ育成を比べる前に

今の目的を明確にします。レベル・ショップ報酬なら必要条件と交換費用を、生産素材なら施設と別の入手経路を比較。費用、周期、代替が不明なまま「開始が遅いと損」という言葉だけで全資源を使わないでください。

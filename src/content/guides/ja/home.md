## 種の設定はどこ？韓国版の画面から探す入口

[韓国プレイヤーHorolの11月27日の図解](https://arca.live/b/azurpromilia/190507810)には3枚の画面があります。流れは **農園の全体画面下部「키보 농장」→畑の右下「씨앗 관리」→「씨앗 창고」の種スロット**。韓国語の原表示であり、日本版の正式なボタン名としては扱いません。

1. 農園が解放済みなら畑の入口へ。未解放なら現在のメイン任務とロック表示を確認します。
2. 種の管理を開き、在庫とスロットの設定を確認します。
3. 投稿の種倉庫には設定順に栽培する説明があります。必要な作物を設定したら畑に戻り、配置と食料も確認してください。
4. まず1回の種まき・作物の変化・回収を確認してから配置を増やします。当サイトでは自動稼働を再現していません。収穫物を自動回収する切替と、種の設定は分けて確認します。

投稿者がレベル21で気づいたことは必要レベルの根拠にはなりません。15〜20分ごとに戻っていたという体験も全作物の生産周期ではありません。画面が異なる場合は自分の版の説明に従ってください。

## 中国本土の初日投稿：栽培・食卓・注文の確認から

11月26日の[TapTap投稿「家园1–15级规划」](https://www.taptap.cn/moment/875088587471717682)は、中国本土プレイヤーの雅中林阁が当日の体験を整理したものです。作者はテスト未参加と明記し、コメントでも補足・修正があります。当サイトで再現しておらず、日本版の解放レベル・配置の確定手順にはできません。

| 中国本土の投稿にある名称 | 投稿が示す操作の手掛かり | 自分の画面で確かめること |
| --- | --- | --- |
| 耕作小屋 | 播種・水やり・収穫の分担、種子管理 | 作業適性、種子在庫、稼働状態 |
| 种子管理 | 高い星数の種子を優先する選択肢 | 貴重な種子の用途と任務の要求 |
| 奇波餐桌 | 食料補充、「一键添加」の案内 | 素材、食料在庫、実際の消費 |
| 订单看板 | 注文の内容に合わせた生産 | 今必要な品と投入量 |

名称は中国本土の原文を残しています。日本版のメニュー名として翻訳対応を保証するものではありません。投稿にあるレベル・枠数を全ユーザー共通の解放条件にせず、今の任務とチュートリアルを優先してください。

## 配置を増やしたら食料不足？追加分の収支を見る

11月27日に確認した[食料消費の個別投稿](https://www.taptap.cn/moment/875286112719866850)は、配置を埋めると食料が不足し、一部の補助効果が消費に見合わないという内容です。完全な比較条件がないため、金色の特性全体が弱い、毎時の収益が一定、といった結論にはしません。

編集部の提案は、まず必須の生産を維持し、同じ時間で食料と生産物の在庫変化を記録することです。その後、補助担当を1体だけ増やして再比較します。手動補給、任務報酬、注文の消費は別に記録。食料が減り続ける場合は、さらに配置を増やす前に補給と不要な担当を確認します。これは公式修正や実測済みの最適配置ではありません。

## 日本版の寮：交流・装飾の販売案内を確認

[日本の正式サービス開始告知](https://azurpromilia.jp/news/5225)は、農園内に「寮」を置いてキャラと交流できると説明しています。塗山小玉専用「春還る花亭」は2027年1月5日04:59まで、メーツァ専用「翠緑の秘苑」は常設販売。装飾、寝間着、アイコンなどのセットで、生産施設の必須条件や効率上昇を確認したわけではありません。無料報酬とも分けて判断しましょう。

## 農園で最初に解決したいこと

正式版の解放に必要なクエスト、施設操作、配置条件はまだ照合が完了していません。本ページでは報酬・生産・配置を分け、初回の解放と生産の記録を助けます。未検証の建築順や完成効率表は提示しません。

中国本土の11月20日特典画像は、恒常入手の区分で農園レベルと農園ショップに中国語名「纯粹忆痕」各×8を掲載しています。ログイン配布、無償・無制限交換、施設の毎時生産量を示すものではありません。日本向けには別の確認が必要です。

## 公式に紹介されている遊び方

中国本土App Storeの開発元説明には、開墾、栽培・孵化、装備製作と、キボによる栽培・採集・製作・生産の協力が記載されています。具体的な施設名、投入、配置能力は正式版で確認する必要があり、全キボが全作業を担当できるという意味ではありません。

日本向けGoogle Playは、キボと協力して「農園」を管理し、敵と戦うと説明しています。以下では日本公式の表記に合わせ「農園」と呼び、中国本土の作業一覧を日本の全施設規則にはしません。

| 体験したいこと | 正式配信後に確かめる結果 | 残す根拠 |
| --- | --- | --- |
| 開墾・栽培 | 利用可能な作物を一度栽培し収穫 | 解放に必要なクエスト、種・材料、開始・受取前後の在庫 |
| 孵化 | 現在可能な孵化を一度完了 | 卵の入手元、装置、費用、時間、結果 |
| 装備製作 | 解放済みレシピで一品作成 | レシピ入手元、材料、製作と任務報酬の区別 |
| キボの協力 | 配置前後の状態を比較 | 個体能力、作業条件、生産、停止表示 |

正式版での確認目標であり、架空の任務名や建築順は追加していません。日本配信の1:10:14以降にも農園の説明がありますが、自動字幕と映像を照合できるまで効率・相場・施設レベルは補いません。

## 報酬と生産を別々に見る

| 項目 | 最初の確認 | そのまま推測できないこと |
| --- | --- | --- |
| 農園レベル報酬 | 必要レベル、受取場所、受取済みか | 毎レベル同じ数がもらえる |
| 農園ショップ | 通貨、在庫、更新、購入前提 | 公告の総数を無償で一括入手できる |
| 施設生産 | 材料、配置、時間、保管、受取操作 | 報酬表の数値が毎時収入になる |
| キボの配置 | 必要能力、配置状態、不足条件 | レアリティが高ければ常に最適 |

## 初回解放時の確認順

1. 現在の任務やロック表示で、任務名と前提を確認。他地域やテスト版のレベルで代用しません。
2. システムの説明を読み、最初に使える施設、用途、費用、操作場所を記録します。
3. キボの配置を求められたら必要能力を照合。能力の根拠がなければランキングだけで育成しません。
4. 開始前の在庫、投入、終了予定と、受取後の変化を比較。一度きりの任務報酬を継続生産に混ぜません。
5. 終了前に保管、計時、停止条件を確認。オフライン継続と上限は規約や再現記録で調べます。

確認の順序であり、正式版が必ずこの5段階で解放されるという意味ではありません。該当項目がない場合は現在の画面とバージョンを残し、推測で埋めないでください。

## 生産が進まないとき

解放完了、施設開始、材料、配置条件、経過時間、保管上限、手動受取の順に確認します。一度に変える条件を絞り、前後を記録。単独の結果から全施設のオフライン仕様を一般化しません。

| 記録 | 残す内容 |
| --- | --- |
| 地域・版・施設 | 画面の正式名称 |
| 任務と配置前提 | 表示条件と達成状況 |
| キボと能力 | ゲーム内の原文 |
| 投入・時間・生産 | 開始前、終了時、受取後を分ける |
| 停止理由 | 満杯、材料、配置、未解放、未特定 |

## 拡張とキャラ育成を比べる前に

今の目的を明確にします。レベル・ショップ報酬なら必要条件と交換費用を、生産素材なら施設と別の入手経路を比較。費用、周期、代替が不明なまま「開始が遅いと損」という言葉だけで全資源を使わないでください。
